# v17 무릎 보호대와 설포
무릎 앞면은 원근에 맞춘 육각형으로, 부츠 설포는 기울어진 직사각형으로 보강했습니다. 흰 면에 미세한 명암과 회색 가장자리를 적용했습니다.
20프레임 관절 좌표는 v16과 동일하며 Unity에서 20프레임을 렌더링했습니다. 콘솔 오류 없음. 데모, 프리팹, Exports/RightWalkSheet.unitypackage를 v17로 갱신했습니다.
재현: LocalTools/Analysis/bake_walk_v17.py. 실행 중에는 전신 스프라이트를 교체합니다. 총은 아직 상체 그림에 포함됩니다.

사용자 요청으로 v17 적용을 취소했습니다. 현재 데모·프리팹·내보내기 패키지는 v16으로 복원되었습니다. 평면 도형을 덧붙인 방식은 채택하지 않습니다.
