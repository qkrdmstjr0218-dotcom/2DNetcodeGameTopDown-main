# 로비 설정 / 게임 종료 — 2026-10-26

후속 사용자 지적으로 현재 로비 설정 안의 게임 종료 버튼은 제거했다. 로비의 독립 종료 버튼만 유지하며 설정은 높이350/음량·소리 테스트·닫기로 정리했다. 아래 설정 내부 종료 설명은 최초 구현 당시 기록이다. 최신 상태는 Docs/READY-GUIDE-2026-10-26.ko.md 참조.

사용자 요청에 따라 기존 로비 패널 오른쪽 위에 설정(80×34)과 게임 종료(105×34) 버튼을 배치했다. 기존 청록 버튼·한글 폰트·패널 스타일을 재사용하고 방 이름/생성·연습·튜토리얼·방 목록의 배치는 유지했다.

## 동작

- 설정은 기존 전체 음량/효과음 슬라이더·소리 테스트·저장 설정을 공유한다. 로비에서는 '닫기 · ESC'와 '게임 종료'를 표시하고, 경기 중의 '계속하기'/'로비로 나가기' 흐름은 유지한다. 로비 문구는 경기 진행 중이라는 안내 대신 음량 안내로 바꿨다.
- 게임 종료는 확인창을 거친다. 왼쪽 게임 종료/오른쪽 취소이며, 확인 전에는 종료하지 않는다. 로비에서 직접 열었다 취소하면 로비로, 설정에서 열었다 취소하면 설정으로 돌아온다. ESC도 동일한 취소/복귀 규칙이다.
- 빌드의 확인 동작은 Application.Quit(), Unity Editor에서는 플레이 모드만 종료한다. Editor API는 UNITY_EDITOR로 가드했다. 설정 자체는 Time.timeScale을 변경하지 않는다.
- 팝업이 열린 동안 로비의 GUI.enabled를 끄고, 로비와 팝업을 같은 OnGUI 흐름에서 순서대로 그린다. 초기 시각 검사에서 다른 컴포넌트의 로비 패널이 설정창을 가리는 문제를 발견해 수정했다. GUI 상태는 호출 후 복원한다.

## 확인

Windows64/Mono 빌드를 최신 상태로 갱신했다: Builds/Review-20261026/Foundry.exe, 오류0/최종경고1(Pipeline 자동화용 RuntimePipelineConfig 없음)/709,650,618bytes. 최근 탄환·사운드 조정도 포함한다. 첫 빌드의 편집기 미반영 경고는 파일 수입 동기화 후 재빌드하여 해소했다(첫71.5초,최종증분10.9초). 폐기예정RPC/Physics 경고는 최초 컴파일 로그에 남아 있으며 별도 수정하지 않았다. Development 아닌 명시적 검증 정의 ARENA_BUILD_REVIEW 빌드로, 검증 인자를 주지 않으면 일반 게임처럼 시작한다. 실행 파일과 같은 폴더의 Data/DLL/Mono 구성이 함께 필요하다.

LocalTools/Analysis/LobbyControls-2026-10-26/review.csx로 실제 제품 콜백을 실행해 28항목 PASS. 1920×1080/1366×768에서 로비·설정·종료창을 캡처하고 최종 사진을 육안 확인했다. 전체/효과음 적용·저장·원래 설정 복원, 취소/ESC 핸들러 복귀, 기존 혼자 연습 진입·설정에서 방 나가기 취소·대기실에서 취소·연결 종료 후 로비 복귀를 확인했다. 마지막에는 실제 ConfirmQuit를 호출했고 Editor가 정지한 것을 외부 상태 조회로 확인했다. 설정 값과 검사 전 Game View 해상도를 복원한다.

내부 Game View 마우스 이벤트 주입은 UI 입력과 맞지 않아 통과 근거로 사용하지 않았다. attempt-input-coordinates.txt/attempt-scaled-input.txt/input-probe.csx를 보관했고, 최종 result.txt는 버튼이 호출하는 제품 API·렌더 검사 결과다. ESC는 최종 검사에서 공통 ESC 핸들러를 호출한 결과이며 OS 키 입력 검사가 아니다. 배경 입력 차단은 GUI 비활성화 코드와 표시 상태를 검토했다. 직접 OS 클릭·키 입력은 하지 않았다.

draw-order-before에는 그리기 순서 수정 전의 실패 사진/기록을 보관한다. 최종 사진은 lobby-1920.png/lobby-1366.png/settings-1920.png/settings-1366.png/quit-1920.png/quit-1366.png다. final-state.json과 빌드 기록은 같은 자료 폴더에 보관한다. Windows 빌드의 실제 창에서 마우스로 종료하는 경로·실제 인터넷 멀티는 이번에 실행하지 않았다. 무기/점수/맵/사운드 변경이나 커밋·푸시는 하지 않았다.
