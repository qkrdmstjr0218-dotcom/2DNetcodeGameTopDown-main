# 보행 참고 시트 관절 검토

참고: 사용자 제공 480×880 PNG의 5번째 줄, 오른쪽 방향. 셀 60×110,
각 프레임 원점은 (60*i,440). 원본 픽셀을 확대하여 8개 프레임을 직접 확인함.
이전 walk-cycle-study의 골반 y≈59는 실제 다리 시작보다 상당히 위에 있어 폐기함.
새 골반 연결점은 대략 y=73~74. 무릎은 대략 y=79~87, 발목은 대략 y=91~100.

분석 표시의 A는 가까운 다리, B는 먼 다리로 해석한 연속 대응임.
해부학적 왼쪽/오른쪽 확정 이름은 사용하지 않음. 손·몸에 가려진 골반 연결점은
점선으로, 1/5 프레임에서 겹쳐 가려지는 B 지점은 빈 표시로 구분함.
실제 해부학적 관절 중심은 그림만으로 확정할 수 없음. 좌표는 수동 추정이며
실측 모션 캡처나 정확한 3D 리깅 값으로 취급하면 안 됨.

확인된 핵심:
- 3번: A의 발목은 몸 뒤쪽, B의 발목은 앞쪽. 두 다리가 벌어짐.
- 7번: A의 발목은 앞쪽, B의 발목은 뒤쪽. 동일한 다리의 역할이 교대함.
- 4번과 8번: 뒤쪽 다리의 무릎이 굽혀지고 발 자세가 달라지며 회수됨.
- 1번과 5번: 다리가 겹쳐 전후 위치만으로 좌우 대응을 확정하기 어려움.
- 무릎/발목뿐 아니라 발의 회전과 팔의 반대 방향 흔들림도 바뀜.

브라우저 확대 검토에서 1~8 프레임을 각각 선택하여 선이 해당 다리 윤곽 안에
들어가는지 확인함. 3/7, 4/8은 반 사이클 비교에 특히 유용함.
현재 커스텀 전신 6프레임은 이런 다리 역할 교대가 충분히 표현되지 않아
재생 순서나 속도만 바꿔 완성할 수 없음. 새 원화 제작 전 A/B 반 사이클 교대,
발 회수, 마지막→첫 프레임 연결을 먼저 검증해야 함.
