# 대기실 사격 게시판·AI 난이도·표시 개선 (2026-10-28)

## 반영 사항

- 벽 게시판의 높이를 되돌리고, 하단에 `조작 가이드 / 경기 규칙 / 무기 · 보급 / 위치 안내` 사격 표적 4개를 배치했다. 표적을 맞히면 게시판 안의 내용이 교체된다. 선택된 표적의 상태등과 짧은 피드백음으로 전환을 알린다.
- 서버가 승인한 일반탄·샷건·관통 라이플·유탄 폭발로 전환한다. 일반탄과 샷건은 가까운 지형·플레이어에 막히며, 관통 라이플은 기존 관통 성질을 유지한다. 이동 충돌체는 추가하지 않았다. 늦게 도착한 대기실 탄이 경기 시작 후 안내를 바꾸지 않도록 단계·경기 버전을 검사한다.
- 게시판 주제는 서버 NetworkVariable로 공유한다. 기존 `규칙 설명` 버튼과 3개 탭은 개인별로 독립적으로 열어 볼 수 있다. 네트워크 직렬화 변경에 맞춰 온라인 호환 표식을 `foundry-score-20261028-v6`으로 올렸다. 온라인 참여자는 모두 같은 최신 빌드를 사용해야 한다.
- 대기실 중앙에는 맵과 같은 단말기만 남겼다. 해킹 연습 구역의 색 면·점유 효과·문구를 없앴다. 실제 경기의 6개 해킹 구역과 점수 판정은 유지한다.
- 실제 해킹 구역의 스캔은 순간적으로 반대편으로 넘어가는 방식에서 부드럽게 왕복하는 방식으로 변경했다. 공유 시계가 64초에서 돌아갈 때도 위상이 이어지도록 8초 주기를 사용한다.
- 참가자 명단에서 P번호·닉네임·준비 상태를 한 카드에 묶었다. 본인 카드는 청록 배경과 선으로 강조하며, 본인 캐릭터 위에는 작은 청록 삼각 표시를 추가했다.
- 관전 이전·다음 버튼은 높이 36px, 글자 14px과 별도 여백을 적용했다. 부활 패널의 높이도 192px로 늘렸다.
- 경기 조준점은 순위창 등 정보 HUD 위에서 그린다. 설정·규칙·Tab 등 실제 메뉴가 열려 있을 때는 숨긴다. HUD 투명화는 추가하지 않았다.

## 부활 보호 설명

사용자 요청대로 대기실의 `경기 규칙` 게시판과 개인 `규칙 설명` 안에서 설명한다. 기존 경기 HUD의 `보호 N초 · 사격 시 해제` 문구는 제거했다. 시작·부활 후 2초 보호, 발사 시 해제, 완만한 보호 시각 효과는 유지한다.

## AI 난이도

혼자 연습 대기실의 AI 행에 `난이도: 보통` 버튼을 추가했다. 누를 때마다 쉬움 → 보통 → 어려움으로 바뀌고 저장된다. 경기 중에는 변경할 수 없다. 현재 AI 모두에 공통 적용하며 온라인·튜토리얼에는 AI를 추가하지 않는다.

| 조절값 | 쉬움 | 보통 | 어려움 |
| --- | ---: | ---: | ---: |
| 새 표적·피격 반응 지연 | 0.45초 | 0.18초 | 0.12초 |
| 조준 흔들림 크기 | 0.50 | 0.24 | 0.10 |
| 판단 갱신 간격 | 0.90초 | 0.60초 | 0.40초 |
| 발사 시도 간격 | 0.48초 | 0.24초 | 0.12초 |
| 기본 회피 간격 | 3.20초 | 1.70초 | 1.35초 |

회피에는 기존 P번호별 소폭 간격 차이가 더해진다. 실제 발사 간격은 기존 서버 무기 제한을 그대로 통과해야 한다. 난이도에 따라 체력·피해량·탄약·이동 물리를 변경하지 않는다. 난이도 수치는 초안이며 승률이나 난이도 간 공정성을 장시간 측정한 결과가 아니다.

연속 피격 시 같은 공격자의 반응 지연이 계속 새로 시작되던 경계도 보완했다. 같은 생명의 공격자에 대한 유효한 기억이 있으면 최초 반응 시점을 유지한다. 다른 공격자로 바뀌거나 기억이 만료되면 새 지연을 적용한다. 특히 반응 지연이 긴 쉬움 AI가 연사에 맞는 동안 계속 반응을 미루는 일을 방지한다.

## 일반탄 충전 의견 기록 — 이번에는 변경하지 않음

현재는 최대 12발, 사격을 멈춘 뒤 1초가 지나면 초당 4발씩 충전한다. 빈 탄창에서 완전히 차기까지 대략 4초가 필요하다. 한 번에 전부 채우는 재장전 방식은 아니다.

사용자가 전달한 의견:

- 한 번에 전부 충전되는 것으로 예상했다는 플레이어가 있었다.
- 몹을 잡는 도중 탄이 모자라 충전을 기다리면 전투 흐름이 끊겨 불편함이 크게 느껴진다.
- 전투가 끝나고 이동하는 동안에는 다시 차므로 다음 전투를 시작할 때의 부족함은 크게 느끼지 않았다.
- 충전을 기다려야 하는 점이 특수탄 사용과 보급 확보를 유도한다는 장점도 있다.

다음 비교 후보는 **현재 순차 충전 유지 / 지연 또는 충전 속도 조정 / 일정 대기 후 일괄 충전**이다. 몹 상대 지속 사격의 중단 시간과 특수탄 사용 빈도를 함께 비교한 후 결정한다. 아직 어느 방식도 승인·적용하지 않았다.
