# 학원 플레이 피드백 / 검토 대기 — 2026-10-26

> 후속 진행 승인 후 라이플30/순위경계/효과음/준비표기를 적용했고 보호막50은 유지했다. 최신 상태와 검증은 [후속 적용 결과](PLAYTEST-FOLLOWUP-2026-10-26.ko.md)를 우선한다. 아래 내용은 적용 전 질문·검토 기록이다.

사용자가 반입 후 전달한 의견과 질문이다. 실제 멀티 테스트는 아직 할 수 없다. 아래 후보는 확정 요구나 구현 완료로 취급하지 않는다. 이번에는 현재 코드를 확인하고 기록했으며 게임 수치·소리·UI를 변경하지 않았다.

## 승리 / 동점 / 순위 — 현재 구현

- 경기 180초 종료 시 총점(해킹 단독 점유 시간 + 플레이어 처치 점수 + 지원 드론 점수)을 비교한다. 해킹 1초당 1점, 플레이어 처치 +5, 지원 드론 마지막 타격 +5다.
- 최상위 총점 차이가 0.05 미만이면 공동 1위다. 최상위 점수 자체가 0.05 미만이면 '획득 점수 없음 · 무승부'다. 2인 양쪽이 같은 양수 점수면 현재 문구는 '공동 1위'다.
- 처치 수/점유 시간/사망 수/남은 HP에 따른 추가 판별, 연장전은 없다. 정확한 총점까지 같을 때 P번호로 행 표시 순서만 고정하며 승패 우선권을 주지 않는다.
- 결과와 우상단 순위는 동순위 다음 번호를 건너뛴다. 예: 1/1/3/4, 1/2/2/4. 전원 같은 점수면 모두 1위다.
- 코드 확인: ArenaObjectiveMatch.cs의 Score.Total/ServerTick, ArenaObjectiveMatch.ResultsUI.cs, ArenaCombatHud.cs의 RankedScores/DrawRanking.
- 확인할 경계: 점수는 실수이고 표시에는 반올림이 들어가므로 화면 숫자가 같아도 원점수 차이로 순위가 갈릴 수 있다. 승자는 최고점과 비교하지만 순위는 인접 행과 비교하므로 10.00/9.96/9.92 같은 연속 근접값에서 공동 1위 표시 범위와 승자 문구 범위가 달라질 수 있다. 버그 수정은 아직 하지 않았다.
- 제안: 점령 중심 모드라면 공동 순위 유지가 자연스럽다. 반드시 단독 승자가 필요할 때만 '총점 → 점유 시간 → 공동 순위' 같은 규칙을 별도로 결정한다. 킬 우선은 모드의 우선순위를 바꾸므로 자동 채택하지 않는다.

## 소리 — 사용자 체감 피드백

- 총알 발사 소리가 없는 것처럼 느껴진다.
- 착탄/점프/아이템 획득/피격 등 전반적인 효과음이 현재 공장·금속·무장 캐릭터와 이질적이고, 귀여운 플랫포머 쪽에 가깝게 느껴진다.
- 현재 24종은 절차 합성 PCM이다. 일반/S/R/G 발사음 호출은 RightFacingShotPreview 및 분할 파일에 연결돼 있다. 코드 연결 사실은 사용자 귀에 제대로 들린다는 검증이 아니다.
- 발사음 미청취 원인은 미확정이다. 현재 ArenaAudio는 포커스/효과음 설정/클립 로드/거리/보이스 풀/믹스 상한을 적용한다. 이 중 하나라고 단정하지 않는다.
- 후속 제안: 실제 사격에서 재생 여부와 음량을 먼저 확인하고, 짧고 단단한 기계 작동음/금속 착탄/묵직한 피격/절제된 전자음 중심으로 대표 소리 몇 개를 비교 청취한 후 전체에 적용한다. 전체 소리를 단순히 더 크게 하거나 모든 소리에 저음을 추가하는 것으로 끝내지 않는다.
- 재생 신호를 확인한 기존 자동 PASS는 음색·게임 외형 적합성·출력기기 청취 평가를 대체하지 않는다.

## 보호막 / 특수탄 — 현재 값과 검토 후보

- 보호막: 최대 50, 15초. 재획득하면 남은 양에 더하지 않고 50/15초로 재설정한다. 현재 GrantShieldServer에는 기존 보호막 만량 거절 조건이 없으므로 50 상태에서도 픽업을 소비하며 시간을 갱신한다.
- 사용자 후보: 보호막을 추가 획득할 때 더 쌓이도록 하면 어떨지. 미확정/미적용.
- 검토 의견: 무제한 누적은 보급 선점자가 전투와 다음 보급까지 계속 유리해질 수 있다. 우선 현행 50 보충/시간 갱신의 가치와 만량 소비 피드백을 확인한다. 누적 시험이 필요하면 별도 상한과 만료 정책부터 정한다.
- 라이플 R: 플레이어 피해 50, 3발, 간격 1.2초, 사거리 30, 탄속 48. 엄폐와 플레이어 관통을 포함하므로 피해만으로 판단하지 않는다. 사용자 우려는 '너무 강한가'이며 하향 확정이 아니다. 후보 40은 무보호막 100HP 상대 2회 적중 처치에서 3회로 바뀌는 큰 차이다.
- 샷건 S(현재 즉발): 탄환당 8, 5발, 전탄 적중 최대 40. 사거리 5, 간격 0.7초, 보유 6발. 실제 피해는 적중 탄환 수에 따라 달라지고 넉백이 있다.
- 유탄 G: 최대 40/최소 10, 범위 내 위치와 대상 Bounds까지의 거리에 따라 감쇠. 보유 4발. 사용자가 기억한 중앙 최대 피해 40이 맞다.
- 일반탄: 플레이어 피해 10, 보유 12발, 자동 보충. 특수탄은 경기 중 자동 보충하지 않는다.
- 보호막 누적과 라이플 하향을 동시에 적용하면 어느 변경의 영향인지 구분하기 어려우므로 각각 검토한다.

## 대기실 준비 표기

- 사용자 요청: 대기실의 '준비' 표기도 외형을 업그레이드해 달라는 의견을 기록한다.
- 방향 후보: 현재 UI와 맞는 작은 상태 표식/체크/준비·대기 색 구분, 본인 버튼과 다른 참가자 상태의 명확한 구분. 준비 판정·전원 준비·방장 시작 규칙은 별도 변경 요청이 없다.
- 아직 디자인/구현은 하지 않았다.

## 멀티 없이 우선 확인 가능한 항목

1. 실제 단발/연사 발사음 청취, 벽 착탄과 적 피격 구분, 효과음 음색 비교.
2. 검사 fixture로 전원 0점/단독 승리/공동 1위/공동 2위/근접 소수점 점수의 승자 문구·순위·표시 숫자 일치 확인.
3. 보호막 0/일부/50 상태 재획득·만료 직전 갱신·픽업 소비 피드백 확인.
4. 라이플/샷건/유탄의 보호막 유무별 피해·잔량과 체감 비교. solo 결과만으로 실제 대전 밸런스를 확정하지 않는다.
5. 대기실 준비/취소/시작 가능 상태의 가독성, ESC·Tab·결과·복귀, 경사·다리·배경 가독성 확인.

실제 두 PC 동기화·인터넷 참가/퇴장, 배포 빌드·장시간 성능은 이후 검증으로 남긴다. 커밋/푸시는 하지 않았다.
