# 한글·시작 줌·이름 및 피격범위 확인

## 수정
- Active Input Handling은 기존 Both(2) 그대로. 닉네임/방이름 IMGUI 입력란에 안정된 control name 부여, 해당 입력란 포커스 때 legacy IMECompositionMode.On 및 InputSystem Keyboard.SetIMEEnabled(true) 명시. 입력란을 벗어나거나 로비종료/포커스상실/비활성화 시 복원. InputSystem의 IME 활성화 API는 설치된 Keyboard.cs 확인. 기존 문자 입력 경로는 IMGUI로 유지하여 문자를 중복 전달하지 않음.
- 닉네임 저장 요청은 최소 다음 프레임까지, Input.compositionString이 비어 확정된 후에만 정리/저장. 조합 중은 확정 안내, 완료는 '닉네임이 저장되었습니다.'3초. 이름 재편집 시 완료표시 해제. 저장 대기 중 방 입장은 차단하여 이전 이름으로 먼저 접속하지 않도록 함. 한글 문자열 자체 저장/API모드검사와 실제 OS 한영키 조합 성공은 구분(실제 물리IME 청취/입력검증 안함).
- 대기실 모든 캐릭터 발밑에 닉네임 추가. 기존 머리 위 P/준비·명단·Tab·결과 유지, 새 카드 없음. 캐릭터 크기/물리 불변.
- 시작 카메라는 카운트다운의 공통 종료시각/CountdownSeconds로 SmoothStep4.8→5.6. 참가자 대기 중4.8, 3초동안 후퇴, 경기5.6유지. 현재 크기로 맵경계clamp. 별도 게임난수/RPC/게임시간 변경 없음.

## 확인
실제solo검사9조건 PASS(result.txt): IME On/복원, 다음프레임저장, 완료안내/한글 서버전달, 준비/카운트다운, 실제 프레임CSV에서 단조롭게4.8→5.6, Playing5.6. saved/name-under-feet/zoom-start/zoom-end/combat 1366 실제GameView 사진 확인. 테스트 이름 PlayerPrefs/해상도 복원·최종정지. 실제 OS 한글조합은 사용자 재확인 필요. 입력 인식 언어가 영문인지 OS설정 여부는 이 검사로 판정하지 않음.
