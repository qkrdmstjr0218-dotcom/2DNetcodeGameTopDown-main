# 혼자 연습용 AI 플레이어 초안

## 사용

로비에서 **혼자 연습**에 들어간 다음 하단의 **AI 추가 / AI 제거**를 사용한다. 사람 1명 + AI 최대 3명이다. AI는 준비 완료 상태이며 사람도 출격 준비한 뒤 연습 시작을 누른다. 경기 중 인원 변경은 막고, 결과에서 대기방으로 돌아오면 다시 변경할 수 있다. 방을 나갔다 재입장하면 AI는 0명이다. 온라인 방과 튜토리얼에서는 이 기능을 제공하지 않는다.

## 동작 범위

- 서버가 실제 플레이어 프리팹을 생성해 물리 이동한다. 별도 키보드/마우스 이벤트를 주입하지 않는다.
- 기존 지상 적의 지형 경로 그래프를 이용해 경사로로 이동한다. 막힘/높이차에는 점프·공중 추가 점프를 요청하고, 바로 아래 목표에 접근할 때 점선 발판 내려가기를 시도한다. 닫힌 다리 경로는 차단 후 재탐색한다.
- 활성 해킹 구역을 목표로 이동·점유하고, 가까우며 지형에 가리지 않은 다른 플레이어를 만나면 일반탄으로 공격한다. 약간의 조준 오차와 판단 간격이 있다.
- 체력, 탄약 재충전, 사격 간격, 스태미나, 보호막, 피격, 자동 부활, 시작/부활 보호는 기존 플레이어 규칙을 사용한다. 추가 체력·무한 탄약·순간이동을 부여하지 않는다.
- AI도 서로 적이며 개인전 점수·킬로그·Tab·결과·관전에 포함된다. AI 이름은 `AI 2`처럼 P번호로 표시한다.

## 구현상 구분

서버가 AI의 NGO 소유자지만 사람과 동일한 참가자 ID로 처리해서는 안 된다. `ParticipantId`로 서버 사람과 각 AI의 점수/타겟/접촉 간격을 분리했다. `IsLocalHuman`으로 카메라, 로컬 HUD, 마우스 조준, 키보드 입력, 청취 기준을 사람으로 한정했다. 실제 물리·모션 스냅샷의 NGO 소유권은 유지한다.

봇 식별 NetworkVariable 추가로 온라인 호환 문자열은 `foundry-score-20261028-v5`다. 온라인 상대도 같은 최신 빌드를 사용해야 한다. 온라인에 AI가 자동 참가하는 기능은 없다.

## 검증

`LocalTools/Analysis/PlayerBots-2026-10-28/result.txt`의 최종 통합 검사 **43개 PASS**. 실제 solo host 안에서 생성·제거·정원·별도 ID·로컬 사람 1명·입력 분리·준비·카운트다운 도착·경기·40초 자율 행동·사망·부활·결과·대기방 복귀·재입장을 검사했다.

40초 동안 AI 3명 모두 자율 이동·판단했고 사격은 각각 2~5회, 2명은 점프를 요청했다. 위치 이동 합계에는 실제 사망 후 자동 부활 위치 변경도 포함되므로 이를 순수 보행 거리로 해석하지 않는다. 최종 결과 사진에서 AI 2의 해킹 점수 21.0을 확인했다. 처치 점수 분리와 부활 검사는 별도로 서버 치명타를 주입한 fixture를 포함하므로 모든 처치가 자율 사격으로 발생했다고 주장하지 않는다.

초기 생성 코드가 Spawn 이전 NetworkVariable을 수정해 경고를 발생시켰다. 일반 필드에 예약하고 OnNetworkSpawn에서 네트워크 값을 쓰도록 수정 후 통합 검사를 재실행했다. 이동 경로의 다리 닫힘 재검사도 최종 검사에 포함한다. 초기 결과는 first-result.txt로 별도 보존했다.

대기방·경기·결과 화면을 확인했고 대기방 버튼 높이를 보정했다. 최종 UI 사진은 1366×768 / 1920×1080이다. 빌드 결과와 경고 목록은 같은 폴더 build.json / build-messages.txt에 기록한다.

## 한계 / 후속 후보

처음 사용하는 자율 상대의 초안이다. 모든 구역/다리 상태에 대해 최적 경로를 보장하지 않으며, 사람 크기와 지상 적용 그래프의 차이 때문에 장애물 앞에서 망설이거나 우회가 길어질 수 있다. 정교한 점프 경로, 아이템 파밍, 적 몹/지원 드론에 대한 표적 판단, 특수탄 선택, 난이도 조절은 아직 없다. 원격 클라이언트가 포함된 AI 경기나 장시간 성능 검사는 하지 않았다.

씬/기존 밸런스 수치/음원은 이번 변경에서 수정하지 않았다. 직접 OS 클릭·키 입력, 커밋·푸시는 하지 않았다.

최종 `Builds/BulletShot/2DNetcodeGame.exe` 일반 Windows64 Mono 빌드 성공: 오류 0, 기존 경고 5, 31.67초, 710,017,914 bytes. 이번 최종 빌드에는 ServicesCore 경고가 없었다. 에디터 플레이는 종료하고 씬은 dirty 없이 유지했다.
