# v44 손잡이, 양손, 목 연결

v43 원화는 수직 손잡이가 없고 손이 총몸을 잡고 있었습니다. 숫자로 손 접점이 맞는 것과 실제로 방아쇠 손이 올바른 위치에 있는 것은 다른 문제였습니다.

`Weapon-Hands-Repair-Reference-v44.png`는 아래로 내려오는 손잡이, 방아쇠/가드, 손잡이를 쥐는 장갑과 앞쪽 아래를 받치는 장갑을 함께 보정한 원본입니다. `RightWalk-WeaponHands-v44.png`는 폭 196px로 등록한 투명 스프라이트입니다. 총과 장갑은 함께 조준하고 상완/전완은 기존 IK로 별도로 움직입니다. 손을 별도로 여는 동작이나 재장전에는 별도 손 원화/포즈가 필요합니다.

총 위치는 x-15/y+24px. 손목 앵커는 등록 이미지 (311.45,166.33), (392,165.32), 총구는 (464.15,143.84). 예전 손 스프라이트를 중복으로 그리지 않아 흰 손목 cuff가 겹치던 문제를 줄였습니다. 머리는 4px 낮춰 목과 옷깃을 겹쳤습니다.

어깨 아래 피부 보정은 이미지 생성 도구 안전 필터가 두 번 거절했습니다. 재생성 대신 v37 상완 윗부분과 v38 완성된 팔꿈치 부분을 조합해 원래 모습으로 복원했습니다. 이중 절단선은 줄었지만 원래 피부/옷 경계는 여전히 눈에 띄므로 해당 부분은 미해결 시각 항목입니다.

20프레임 × -12/0/+12도에서 손목 앵커 오차 0, 도달 불가 0. 흰 배경 세 각도 렌더를 확대해 별도로 확인했습니다. 이 수치 검증은 피부 경계의 완성도를 보증하지 않습니다. 씬, 프리팹, unitypackage 저장.
