# 기존 작업 확인과 독립 걷기 시제품

기존 상태: SFPlayer 프리팹은 OperatorAimVisual의 useRightLegRig=true이며
rightWalkFrames 배열은 비어 있음. 전신 오른쪽 걷기 6프레임 에셋은 별도로 남아 있음.
하체 8프레임 재그림, 뼈대 시험, 원본 전신 8분할 재조립, 관절 소각도 시험 씬이 존재함.
Tools/master-joint-study-notes.md는 관절 절단선과 틈이 남아 보행 확대를 금지한 상태라고 기록함.

새 작업은 Assets/RightWalkPrototype 안에 모음. 기존 네트워크 게임 대신 독립 씬에서
전신 6프레임을 재생하고 입력, 가속/감속, 실제 이동 거리 기반 걸음, 후진 역재생,
제자리 걷기와 속도 비교를 제공함. 그림을 새로 생성한 작업은 아님.
카메라 추적은 시험 씬 전용이며 프리팹에는 이동과 애니메이션만 포함함.

Unity 6000.3.18f1에서 컴파일 오류 없음. Play 모드에서 실제 대각선 이동과 프레임 변경 확인.
대각선 속도 1.8이 설정 속도 1.8과 일치. 입력 해제 후 속도 0과 idle 프레임 0 확인.
카메라 캡처에서 캐릭터의 투명 배경과 격자 위 정상 렌더 확인.

한계: 오른쪽 방향만 그림이 준비됨. 후진 역재생은 첫 시제품 처리이며 전용 뒷걸음 아트가 아님.
기존 AI 생성 그림의 자세와 형태 일관성은 추가 검토가 필요함.
