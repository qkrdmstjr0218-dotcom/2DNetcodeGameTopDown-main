# 기본 캐릭터 실행 파일 아이콘 — 2026-10-26

사용자가 Windows 실행 파일에 기본 캐릭터 썸네일을 넣고 싶다고 요청했다. 실제 게임의 P1 기본색 초상인 Assets/RightWalkPrototype/Art/UI/portrait-1.png(128×160,GUID a3738370fae24bf43a199600dfd086c5)를 그대로 사용한다. 원본 그림/수입 설정/게임의 초상 표시와 제품 이름은 변경하지 않는다.

Unity PlayerSettings의 공통 Default Icon과 Standalone 아이콘8개 슬롯(1024/512/256/128/64/48/32/16)을 해당 Texture2D로 연결하고 저장했다. 크기별 실제 아이콘 변환은 Unity 빌드 과정에 맡긴다. 설정값은 ProjectSettings/ProjectSettings.asset에 저장되며 이후 수동 빌드에도 적용된다.

직접 수정할 때는 Edit → Project Settings → Player의 Default Icon을 지정하거나, PC의 Icon → Override for Windows, Mac, Linux에서 크기별 아이콘을 지정하면 된다. 기존 EXE에는 설정 변경만으로 소급 반영되지 않으므로 다시 빌드해야 한다. 공식 문서: https://docs.unity3d.com/6000.3/Documentation/Manual/playersettings-windows.html#Icon

이번에는 사용자 스크린샷의 실제 출력 경로인 Builds/BulletShot/2DNetcodeGame.exe를 현재 활성 Windows64/저장된 활성씬으로 다시 빌드한다. 기존 실행 파일은 LocalTools/Analysis/AppIcon-2026-10-26/2DNetcodeGame-before.exe에 보관했다(비교용 실행 파일 단독이며 완전한 이전 게임 백업은 아니다). Review-20261026 폴더는 이번 아이콘 적용의 출력 대상이 아니다. 60FPS 제한·최신 로비 버튼/간격·탄환·음원은 현재 소스 기준으로 함께 포함된다.

설정 전 ProjectSettings 복사본, settings.json과 build.json/build-messages.txt는 LocalTools/Analysis/AppIcon-2026-10-26에 보관한다. 직접 OS 클릭·키 입력·커밋·푸시/제품 이름 변경은 하지 않는다.

최종 Windows64/Mono 일반 빌드 성공: 오류0/경고1(Pipeline 런타임 자동화 설정 없음)/23.86초/709637658bytes. 실제 출력은 Builds/BulletShot/2DNetcodeGame.exe이며 검증용 ARENA_BUILD_REVIEW 정의 없이 빌드했다. 저장된 Foundry씬1개를 사용했다. Windows 실행 파일의 아이콘을 System.Drawing.Icon.ExtractAssociatedIcon으로32×32PNG추출하여 기존기본색캐릭터그림임을육안확인했다(exe-icon.png/icon-extraction.json). 원본초상의투명여백과상반신구도도그대로포함된아이콘이다. 탐색기목록갱신/실행중작업표시줄의직접확인은하지않았다. 새아이콘이즉시안보이면폴더새로고침으로확인할수있다.
