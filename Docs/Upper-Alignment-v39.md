# v39 상체 정렬

512px 원화 기준 상체 전체를 골반에 대해 오른쪽 10px 이동. 머리는 상체 기준 왼쪽 6px 이동. 두 어깨/팔 IK의 기준 좌표는 상체 기준 오른쪽 3px, 아래쪽 3px 이동. 총과 상체는 함께 이동하고 손은 총의 Grip 위치를 유지. 하체 궤적과 원화는 유지.

Upper Body Alignment 오브젝트에 상체 전체 이동량이 있으며 Head Pivot과 각 Arm IK 루트에 상대 보정량이 있음. 빌더에 기록되어 재생성 가능. 위/정면/아래 조준 렌더와 양손 도달을 확인. 씬/프리팹/이동용 unitypackage 저장.
