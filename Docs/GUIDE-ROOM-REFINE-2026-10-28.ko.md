# 대기실 후속 수정 — 2026-10-28

## 요청과 변경

### 착탄 예상 표시·위치 안내

일반탄 착탄 예상 X는 `RightFacingAimRig.OnGUI`가 별도로 그렸다. 이 경로에 규칙 창·메뉴 입력 차단 조건이 빠져 있어, 조준이 멈춘 위치의 X가 설명창 위에 남았다. 표시 조건을 공통 `ControlsBlocked`와 대기실 UI 영역에 맞췄다. 규칙 창·설정·Tab·전환 중에는 표시하지 않는다.

일반탄 예상 지점의 X는 작은 네 모서리 표식과 중앙 점으로 바꿨다. 실제 지형을 만나는 예상 지점은 선명하게, 사거리 끝은 옅게 표시한다. 기존 탄환·발사음·사거리·피해는 바꾸지 않았다.

개인 규칙 창의 위치 안내는 별도의 테두리 상자를 제거하고 다른 탭과 같은 16px 본문색으로 통일했다. 아이콘과 설명을 두 행으로 정리하고, 스타일의 내부 여백을 없애 글자 아래쪽이 잘리지 않게 했다. 긴 설명은 줄바꿈한다. Tab의 공통 위치 안내는 기존 크기의 테두리와 13px 글씨를 유지하되 같은 여백 보정을 적용한다.

### 천장 위 라이플 표적

주제 표적 4개를 게시판 하단에서 **실제 천장 위**로 옮겼다. 부모의 0.92 배율·Y 이동까지 적용한 월드 Bounds가 천장 위에 있는지 검사한다. 표적 자체에는 이동 충돌체가 없다. 일반탄·샷건으로는 주제가 바뀌지 않으며, 유탄 폭발의 게시판 전환 경로도 제거했다. 사람 플레이어의 승인된 관통 라이플만 표적을 바꾼다.

게시판의 상단 및 하단에는 `2 관통 라이플 선택 → 우클릭 사격 · 천장을 관통해 주제 선택`을 안내한다. 개인 규칙 창도 같은 방식으로 설명한다. 공유 주제와 개인 규칙 창의 독립성은 유지한다. 동작과 배치가 달라져 온라인 호환 표식을 `foundry-score-20261028-v7`으로 변경했다. 전원 최신 빌드가 필요하다.

### AI 몸 충돌

기존 인간 멀티에서는 `body.simulated=IsOwner` 때문에 원격 플레이어 몸체의 물리가 꺼진다. solo AI는 서버 소유 플레이어이므로 같은 PC에서 여러 몸체 물리가 함께 켜져 서로 밀릴 수 있었다.

이제 플레이어끼리의 BoxCollider2D 접촉을 개별적으로 무시한다. 생성·새 생명 적용 시 설정하며, 바닥·벽·플랫폼·몹과의 기존 설정은 바꾸지 않는다. 바닥 탐색도 무시된 상대 플레이어를 발판으로 취급하지 않는다. 앉았다 일어나기의 기존 IgnoreCollision 필터도 그대로 동작한다. 탄환은 별도의 서버 피격 Bounds를 사용하므로 몸 접촉 무시와 무관하게 맞아야 한다.
