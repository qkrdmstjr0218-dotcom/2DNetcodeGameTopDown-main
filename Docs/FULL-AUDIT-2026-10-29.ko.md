## 발견해 수정한 문제

### AI의 하단 중앙 점령 구역 진입 경로

기존 지상 경로는 걷기로 이어진 표면만 연결했다. 하단 중앙의 낮은 섬 지형은 점프를 해야 들어갈 수 있어 AI가 목적지에서 20유닛 이상 떨어진 경로 끝을 선택하는 경우가 있었다. AI가 점령하러 오지 않는 원인 중 하나다.

- 플레이어 AI에만 실제 점프 속도·중력을 전달해 점프 연결을 생성한다. 기존 몹은 기본 인자를 사용하므로 점프 기능을 얻지 않는다.
- 걷기 그래프의 서로 다른 연결 영역 사이만 검사한다. 같은 바닥의 불필요한 점프 연결과 중복 궤적 검사를 줄였다.
- 단일·추가 점프의 궤적을 검사하고, 바닥 지지 및 몸통·머리 공간을 확인한다. 지형과 플레이어 물리 수치는 바꾸지 않았다.
- 접힌 다리의 잠재 경로 노드가 높이 0에 생기던 오류도 실제 `bridge.floor`로 보정했다.
- 양방향으로 연결하는 경로이므로 닫혔던 연결 재검사도 양쪽 통과 가능 여부를 확인한다.

검증: 여섯 점령 구역의 36개 출발/도착 조합, 하단 중앙 양쪽에서 실제 모터 이동·점프·영역 진입 등 44개 확인 통과. 이는 모든 임의 위치에서의 경로 완전성을 증명하지는 않는다.

### 웹 혼자 연습의 통신 방식

기존 혼자 연습·튜토리얼도 UnityTransport 로컬 호스트를 사용했다. 설치된 Transport 소스는 웹의 직접 서버 시작을 거절한다. 웹에서는 외부 패킷을 보내지 않는 내부 호스트용 `ArenaOfflineTransport`로 전환하고, 인터넷 방에 접속할 때 기존 UnityTransport로 복원하도록 보완했다. Windows의 기존 로컬·Relay 통신 선택은 유지했다.

방 목록 재시도 간격은 관리 타이머 `Task.Delay`에서 Unity 프레임을 기다리는 비동기 대기로 변경했다. 웹 로비에서는 기능하지 않는 게임 종료 버튼을 숨겼다. 웹의 실제 브라우저 검증 범위와 남은 항목은 [웹 준비 점검](WEB-READINESS-2026-10-29.ko.md)에 기록한다.
