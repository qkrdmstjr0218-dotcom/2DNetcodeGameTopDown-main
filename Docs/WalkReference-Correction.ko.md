# 사용자 표시를 기준으로 한 관절 수정

참고 이미지의 오른쪽 방향 8프레임을 60×110 셀 좌표로 기록했다.
각 다리의 순서는 골반 → 무릎 → 발목 → 발끝이다.

이전 4·8번의 뒤쪽 다리에서 발목을 무릎으로, 발끝을 발목으로
읽은 오류가 있었다. 접힌 무릎은 몸 앞쪽에 있고, 종아리는 뒤쪽
발목으로 이어지며, 발목 아래의 발은 별도 구간이다.

3번에서는 A가 뒤/B가 앞, 7번에서는 A가 앞/B가 뒤로 교대한다.
사용자가 그린 선을 기준으로 수정했지만 가려진 골반, 겹친 다리,
A/B의 연속 대응은 추정이며 정확한 해부학 측정값은 아니다.

기존 6프레임 캐릭터 그림에는 아직 이 수정이 적용되지 않았다.
기존 시제품과 내보내기 패키지는 완성된 보행 아트가 아니다.
새 좌표는 LocalTools/Analysis/right-walk-reference-joints.json에 있다.

## 5~8번 좌표 정렬 재수정

1~4번 좌표는 유지했다. 5~8번은 두 번째 보강본에서 직접 읽은
관절 픽셀을 원본 셀로 변환했다. 각 프레임의 표시가 없는 머리
영역을 비교해 배율(약 2.825)과 위치를 구했고, 모든 프레임에 같은
위치를 가정하던 방식을 없앴다. 이전 무릎 높이의 오류를 수정했다.

변환값과 보강본의 관절 픽셀은 JSON에 함께 기록했다.
브라우저에서 5·6·7·8번을 각각 확대해 선과 원본이 겹치는지 확인했다.
손으로 그린 선의 관절 중심은 근사값이며, 캐릭터 아트 적용 전 단계다.
