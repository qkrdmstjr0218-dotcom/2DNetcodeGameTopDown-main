# 오른쪽 전신 기준 그림 v1

내장 이미지 생성 도구 사용. 원본 컨셉과 기존 8방향 아틀라스의 E 포즈를 참고해 한 장으로 그린 전신 후보.
이미지: Assets/Art/OperatorPrototype/operator-right-fullbody-master-v1.png
프롬프트: Tools/operator-right-master-prompt.txt

상하체가 일관된 그림이며 허리/골반 연결은 그림 자체에 포함됨. 기존 게임 스프라이트보다 길쭉한 비율로 생성되었으므로 동일 비율이라고 주장하지 않음. 발 방향도 순수 측면이 아닌 아래쪽 성분이 있는 기존 컨셉 원근.
현재는 외형 검토용 원화. 파츠 분리/숨은 관절 보충/스켈레톤 적용은 아직 하지 않음. 실패한 기존 파츠에 이 그림을 다시 접합하지 않음. 기존 연구 씬과 게임 프리팹 유지.
