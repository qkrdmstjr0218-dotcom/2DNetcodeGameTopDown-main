# 관절 윤곽 분할 수정

MasterJointV3 메시: 이전 높이 중심 직선/사선 절단을 장갑 가장자리를 따라 잡은 다점 경계로 변경. 원본 텍스처 유지.
무릎 원형 연결부 전체를 허벅지 측에 남기고 종아리 앞 파란 장갑의 상단을 포함하도록 경계 보정. 발목 원형 연결부는 발 측에 유지.
NEXT PART / ALL PARTS로 하나씩 확인 가능. 관절 임시 받침은 기본 OFF로 변경.
근접 종아리 단독 캡처 master-contour-shin-v3.png, 회전 캡처 master-contour-motion-v3.png.
분할 개선은 진행됐으나 발목 경계에 다른 장갑 조각이 일부 남고 회전시 노출 경계가 보임. 완전한 윤곽 분리나 숨은 관절 보충 완료로 간주하지 않음. 걷기 확대 전 추가 정리가 필요함.
