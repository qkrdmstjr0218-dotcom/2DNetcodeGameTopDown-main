# 일반탄 자동충전과 조준점 탄약 링 · 2026-10-20

현재 `RelayArenaPrototype` 준비방 경기 흐름에 적용했다. 오래된 로컬/네트워크 씬과 `useReadyRoom=false`인 집중 검사들은 기존 일반탄 무제한 규칙을 유지한다.

## 조작과 표시

- 일반탄은 처음12발. 발사1회에1발을 사용한다. 마지막 유효 일반탄 발사 후1초가 지나면 초당4발 속도로 회복한다. 소수 잔량도 누적하고 한 발 이상 모여야 발사할 수 있다. 첫 시험 수치이며 최종 밸런스 확정이 아니다.
- 사격 간격·탄속·사거리·피해는 바꾸지 않았다. 빈 탄창에서 발사를 유지하면 한 발이 충전될 때 발사할 수 있으며, 충전 지연은 버튼 입력이 아닌 마지막 유효 발사를 기준으로 한다.
- 조준점은 실제 마우스 위치다. 주위 분할 링은12시에서 시계방향으로 배치하고 부분 충전은 다음 칸이 차오르게 표시한다. 일반탄은 청록12칸, 샷건은 노랑6칸. 중앙은 비우고 완충 시 링만 흐리게 한다. 큰 탄수로 설정하면 최대32분할로 묶어 표시한다.
- 오른쪽 아래 작은 패널에는 일반탄 현재/최대, 샷건 현재/최대, 현재 발사 탄종과 선택 탄종을 표시한다. 일반탄 숫자는 실제 발사 가능한 정수 잔량이다.
- Q/E 선택·우클릭 유지 중 선택탄·놓으면 일반탄인 기존 조작을 유지한다. 링은 선택 칸 자체가 아닌 **실제 지금 발사할 탄종**을 표시한다. 샷건을 다 쓰면 기존처럼 일반탄으로 이어진다.
- 플레이 중 링이 보이면 OS 커서를 숨긴다. 메뉴/대기방/관전/전체 지도/연결 종료/포커스 이탈에서는 OS 커서를 복구한다. 기존 사거리/착탄 지점의 X 표시는 유지했다.

## 서버 규칙과 설정

설정 원본은 `Assets/RightWalkPrototype/ArenaObjectiveMatch.prefab`의 Normal Ammo Capacity(12), Normal Ammo Recharge Delay(1), Normal Ammo Recharge Rate(4)다. 실행 시 서버가 읽어 전원에게 공유한다. 다음 실행에서 이 설정 하나로 실제 탄약과 UI가 바뀐다.

서버가 일반탄 잔량·발사 간격·충전 시점을 결정한다. 소유자 UI는 서버의 잔량을 읽는다. 유효한 생명 세대/소유권/발사 원점·방향/연사 제한을 통과한 발사만 차감한다. 이전 무제한 RPC 경로는 현재 경기에서 거절한다. 빈 탄창, 대기/카운트다운/종료, 이전 생명의 요청은 탄약을 사용하거나 탄환을 만들지 않는다.

사망 중에는 충전하지 않고, 경기 종료 시에도 정지한다. 자동부활/새 경기/대기 복귀/새 접속 때 최대치로 복구한다. 단순 위치 초기화는 탄약을 채우지 않는다. 경기 중 메뉴/전체 지도를 보는 동안에도 게임은 계속되므로 사격하지 않으면 일반탄은 회복한다. 샷건 발사는 일반탄 잔량을 차감하거나 충전 지연을 다시 시작하지 않는다. 샷건 자체는 자동충전하지 않는다.

FPSbasic의 자동충전 조건과 상태 분리 구조를 참고했으며 3D 무기/발사체를 복사하지 않았다. 차징/수류탄은 아직 구현하지 않았다. 사용자가 교정한 미래 차징 UI는 막대가 아니라12시부터 시계방향으로 차오르는 원형 게이지다.
