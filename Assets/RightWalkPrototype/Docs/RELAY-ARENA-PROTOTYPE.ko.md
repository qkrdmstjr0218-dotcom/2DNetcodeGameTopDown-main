# 중계 시설 07 · 첫 전투 맵 시안

씬: `Assets/RightWalkPrototype/Scenes/Network/RelayArenaPrototype.unity`.

## 실행

- Main Editor와 Virtual Player가 모두 **새 씬**을 열어야 한다. 이전 시험 씬이 열린 Virtual Player는 새 씬으로 전환한다.
- 기존과 같이 Main에서 Local Host, 참가 화면에서 Local Client. 최대4인을 위한 개별 시작 지점과 P번호를 사용한다.
- A/D 이동, Shift 달리기, Space 점프·공중 추가 점프, 마우스 조준/사격, S/↓/Ctrl 앉기. **Tab은 전체 맵 보기/플레이 화면 전환**이다.
- 낙사 시 서버 HP0/기존 쓰러짐으로 처리한다. `복귀 (시험)`로 본인 시작 지점에 돌아온다.
- 새 맵에서 사거리는 임시24로 연장했다. 이 맵의 시험값은 걷기2.4 / 달리기3.6 / 앉기.9 / 점프 속도6.5로 올렸다. 이전 시험 씬과 보존 프리팹 수치는 유지하며 캐릭터·카메라 배율도 유지한다. 모두 추후 조정할 대상이다. 사용자의 전체맵 언급은 향후 캐릭터 표시 크기 검토였으며, 전체맵 화면에 대한 거절로 해석하지 않는다.
- 경사로 아래를 수평으로 지나갈 때는 자동으로 올라타지 않는다. **점프해서 위에 착지하면** 경사로를 걸어 오를 수 있고, 서 있을 때 미끄러지지 않도록 접지 상태에서 지지한다.
- **격자 발판/경사로에서 앉기+Space**: 아래4.2 이내에 충분한 낙하 공간과 안전한 착지 지형이 있을 때 내려간다. 일반 단단한 바닥은 통과하지 않는다. 통과형 상자 위에서도 아래 바닥으로 내려갈 수 있다. 낙사 구덩이 안쪽 착지는 허용하지 않는다.
- 플레이 화면에 포커스가 있고 접속 중이면 마우스를 화면 안으로 제한한다. **ESC**로 메뉴를 열어 제한을 풀고 본인 이동/조준/사격 입력을 막는다. 다른 참가자의 게임은 계속 진행된다. 계속하기/ESC로 닫고, 마우스 버튼을 놓은 뒤 사격을 재개한다. 포커스 상실·연결 종료·Play 종료 시 제한을 푼다.

중간층 좌우·상층 데크는 단단한 지형으로 복원했다. 중앙 격자/경사로만 단방향 지형으로 남는다. 상자는 옆과 아래에서 몸이 통과하고 위에서는 착지하지만 탄환은 막는 시험 엄폐물이다. 지상 상자는 중앙 격자 아래 x±3.6으로 옮겨 서 있을 공간을 확보했다. 경사로도 동일한 단방향 원리에 플레이어별 충돌 허용 상태를 조합한다. 특정 구역 좌표에 입력을 붙이는 방식은 아니다.

## 이동 구조와 외형

- 폭46, 주 바닥 높이0 / 중간층3.2 / 상층6.4. 양쪽 외곽 경사로가 바닥과 중간층을, 안쪽 경사로가 중간층과 상층을 연결한다.
- 중앙은 탄환과 아래쪽 캐릭터가 통과하고 위에서 내려올 때 착지하는 격자 발판이다. 경사로도 격자 형식이라 아래에서 머리가 걸리지 않고 탄환을 통과시킨다.
- 일반 바닥·중간층 좌우·상층 데크는 캐릭터와 탄환을 막는다. 주황 연속선은 고체 면, 청록 점선은 몸이 통과하는 면이다. 상자 아래 바닥선은 끊지 않는다. 표시선은 해당 지형/상자에 부착한다. 상자는 청록 점선 윗면/황색 엄폐 패널을 함께 표시한다.
- 아래로 내려가도 경사로로 돌아올 수 있다. 기본 경로가 끊기는 구간을 줄이고 큰 중앙 공간과 양쪽 경로를 남겼다. 적 이동은 이후 AI 설계 시 사용할 공간이며 AI/내비게이션은 아직 없다.
- 외형은 어두운 중계 시설: 서비스 패널, 배관·트러스, 층별 청록/황색 테두리, 시설·구역 표식, 다리 상태등. 기존 단색 스프라이트를 재사용한 시설 테마 시안이며 최종 배경 원화/조명 작업은 아니다.

## 달리기 스태미나 시험

새 맵 네트워크 플레이어에만 적용한다. Shift+방향으로 실제 걷기보다 빠르게 이동하는 동안 초당25 소모한다. 최대100, 사용 중단 후1초 대기하고 초당20 회복한다.0이면 달리기를 막아 걷기로 전환하며20 이상 회복하면 다시 허용한다. Shift를 계속 누른 경우에도 회복 기준을 넘으면 달리기를 재개할 수 있다.

걷기/정지/앉기 자체는 소모하지 않는다. 점프에 별도 비용은 없다. 공중에서도 Shift+방향으로 달리기 속도를 사용하고 있다면 그 지속 시간에 대한 소모는 계속된다. 벽에 막혀 실제 달리기 속도가 나지 않으면 소모하지 않는다. 메뉴/종료 입력 차단 상태에서는 달리기 요청을 해제한다. 사망 중 잔량은 멈추며, 본인 복귀와 새 경기 시작은 최대치로 재설정한다. 위치 초기화 버튼은 잔량을 채우지 않는다.

서버가 잔량/고갈을 결정하고 클라이언트에 동기화한다. 본인 왼쪽 아래 HP 창에 수치와 막대(청록, 고갈 시 황색/회복 중)로 표시한다. 이전 로컬 완성본·옛 네트워크 시험 씬은 무제한 달리기를 유지한다. 수치는 실플레이 조정용 시안이다.

최신 스태미나 검증: objective-120200/result.txt PASS.4인 소모/고갈/회복/개별 동기화, 걷기·앉기·점프 무소모와 메뉴/사망/복귀/새 경기 초기화를 확인했다. 스태미나 HUD 캡처도 보존했다.
