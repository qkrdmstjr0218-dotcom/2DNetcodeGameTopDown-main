# 전투 HUD 적용 · 2026-10-24

화면을 가리던 시험용 패널을 실제 RoomFlow 경기에서 숨기고 축소 HUD를 적용했다. 로비·대기실·튜토리얼·결과 화면은 기존 흐름을 사용한다.

- 좌상단 P번호/HP와 HP·보호막·스태미나 바, 상단 시간, 우하단 일반탄 아이콘/S/R/G 현재·최대 잔량.
- 선택 특수탄 테두리와 실제 사용 탄종의 밝은 윗선을 구분한다. 빈 잔량은 빨강이다. 충전 대기/입력 설명은 생략했다.
- Tab을 누르는 동안 지형 지도와 점수 내림차순 참가자 목록(실제 번호별 초상/P번호/HP/점수/처치), 득점 규칙을 표시한다. 닉네임·채팅·상시 순위·킬 로그는 추가하지 않았다.
- 지도는 맵 하위 지형 충돌체만 그린다. 현재 구역과 실제 개폐 다리 상태는 표시하되 플레이어·적·픽업 위치는 그리지 않는다. 게임 카메라 확대나 위치 전환도 하지 않는다.
- 현재 해킹 구역은 마름모·구역 교체까지 남은 게이지로 안내한다. 다음 구역/거리/명칭 패널을 제거했다. 지원 드론은 방패·방향 마크만 사용하며 규칙 창에 지원 드론 격추 +5로 명시한다.
- 자신의 머리 위 중복 정보는 숨기고, 상대 머리 위 P번호/HP·보호막 막대는 유지한다. 작은 십자 조준점과 짧은 발사 대기 호를 사용한다. S/R 사거리 안내와 G 예측 궤적은 기존 계산을 유지한다.
- Tab 중 사격·조준 안내를 차단하며 이동과 서버 시간은 계속 진행한다. 닫을 때 마우스를 계속 누르고 있었다면 버튼을 놓고 다시 눌러야 사격한다. ESC/포커스 상실/방 전환이 우선한다.

## 가독성/정보 한 줄 배치/개폐 다리 상자 정정 · 2026-10-25

최신 사용자 요청으로 머리 위 P번호를 바 왼쪽, HP 숫자와 `(+보호막)`을 오른쪽으로 묶고 전체 그룹을 중심 정렬한다. 보호막/HP/본인 스태미나 게이지는 유지하고 별도의 보호막 잔여 초 문구는 제거했다. 좌상단에도 `HP / 최대HP (+보호막)`을 표시한다. 배경 카드 없는 머리 위 구성과 기존 조준점/탄약 기능을 유지한다.
