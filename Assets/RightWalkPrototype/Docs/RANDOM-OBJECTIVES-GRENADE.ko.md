# 해킹 지점 무작위·유탄 적 피해 상향

2026-10-22 사용자 요청.

- 첫 해킹 지점도 후보 전체에서 무작위로 선택한다.
- 이후에는 현재 지점을 제외한 나머지 후보에서 서버가 균등 추첨한다. 바로 같은 지점은 반복하지 않지만 한 지점을 건너뛴 재등장은 가능하다. 전체 후보를 한 번씩 소진하는 셔플 방식은 아니다.
- 현재 지점과 다음 지점(Upcoming)을 하나의 RoundState로 공유한다. 미리 예고한 지점이 전환 시 그대로 활성화되며, 전환한 뒤 그다음 후보를 새로 추첨한다. 안내 화살표/콘솔/텍스트는 공유 NextPoint를 사용한다.
- 후보 하나뿐이면 그 지점을 유지한다. 지점 없는 맵은 기존처럼 경기 시작을 거절한다.
- 유탄의 적 대상 피해3→1을6→2로 상향했다. 기존 폭발 중심에서 대상 피격 범위의 가까운 점까지 거리로 선형 보간한다. 보호막 드론 체력12는 중심 폭발2회로 파괴 가능하다.
- 플레이어 피해40→10/자해/폭발 반경/속도/탄약/간격은 유지했다.
