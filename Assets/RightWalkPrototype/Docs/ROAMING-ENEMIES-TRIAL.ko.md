# 자유 순찰·추적과 전투 드론 · 2026-10-22

Foundry에 기존 지상 로봇2/포탑2와 전투 드론2를 둔다. `ArenaMapSettings.roamingEnemies`로 선택하며 옛 맵은 기존 왕복을 유지한다. 위치는 `patrolRoutes`의 시작점과 `droneSpawns`; Foundry Builder에도 저장했다.

- 지상형: 실제 충돌체 윗면을 따라 연결된 보행 경로를 순찰한다. 시야 내8거리 플레이어를 따라가며 시야를 잃으면3초 뒤 순찰로 돌아간다. 점프/높은 벽 넘기는 미구현이다.
- 드론: 중력 없이 고체 지형을 피하며 비행한다. 감지9/이동2.2/권장 사격 간격3~5. 너무 가까우면 후퇴, 멀면 접근한다. .7초 예고 후 .3초 간격2발, 다음 공격까지2.2초. 피해10/탄속7과 서버 구간 충돌 검사를 사용한다.
- 서버만 경로·이동·표적·사격·피해를 결정한다. 이동10Hz/판단.6초. 전원에게 위치를 전송하고 화면은 보간한다. 막힌 경로는2초 뒤 다시 검사한다.
- 지상형의 바닥이 사라지면 낙하한다. 기존 낙사 위치 판정을 사용하며 정상 하부 통로는 안전하다. 경로망은 라운드 시작에 생성되므로 임의의 런타임 새 지형 편집까지 지원하지는 않는다.
- 체력4/재생성10초/샷건1발50% 드롭과20초 만료는 기존 적 규칙을 공유한다. 공격 드론은 회복팩을 떨어뜨리지 않는다. 별도 구급 드론은 구상 단계다.
