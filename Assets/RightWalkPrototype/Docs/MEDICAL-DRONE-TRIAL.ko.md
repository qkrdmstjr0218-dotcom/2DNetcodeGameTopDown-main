## 이전 회복 드론 구현 이력

Foundry에서 회복을 얻기 위해 이동하거나 사격할 선택이 생기는지 확인하는 기능이다. 기존 고정 회복팩은 비교용으로 유지했다.

- 첫 등장 10~16초, 이후 25~40초 무작위 간격. 좌우 무작위 방향으로 최대 한 대가 맵을 가로지른다.
- 3초 전 접근 방향 예고, 화면 밖 비행 중 방향 표시. 거리/좌표는 표시하지 않는다.
- 공격/접촉 피해 없음. 체력2, 이동속도3.2. 파괴 시 HP25 회복팩 한 개 확정 지급, 자연 퇴장 시 드롭 없음.
- 팩은 중력으로 떨어져 바닥에 놓인다. 드롭20초 소멸, 마지막4초 깜빡임. 만량/사망자 제외 및 동시 단일 획득은 기존 서버 규칙을 사용한다.
- 내부 지형은 비행 그래프로 우회한다. 맵 경계 진입/퇴장만 벽을 통과하며, 맵 밖 피격은 막는다. 경로 실패 시 재시도, 비행35초 초과 시 무드롭 정리.
- 서버가 일정/이동/파괴/회복을 결정한다. 종료/대기 복귀 시 드론과 예약을 제거한다. 기존 일반 적의 재생성 경로를 쓰지 않는다.

설정 원본은 ArenaObjectiveMatch.MedicalDrones.cs의 직렬화 필드, 맵별 활성화는 ArenaMapSettings.medicalSupplyDrones다. Foundry만 활성화했다. 회복량은 기존 healthPickupAmount를 공유한다.
