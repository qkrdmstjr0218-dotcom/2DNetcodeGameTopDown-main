# 90도 조준 시험

- 현재 씬: `Assets/RightWalkPrototype/SideScrollRunRecoveryTrial.unity`
- 해당 씬의 조준 제한을 ±90도로 저장했다. 이전 시험 씬은 그대로 보존했다.
- 총과 양팔 IK는 확장된 각도를 사용한다. 머리와 목은 기존 ±45도 범위의 추종 자세를 유지해 과도한 회전을 막는다.
- 기존 걷기/달리기 이미지와 하체 동작은 변경하지 않았다.
- 정지 상태에서 -90, -75, -60, -45, 0, 45, 60, 75, 90도 목표를 확인했다. 양팔 모두 도달 가능하고 손 접점 오차는 0.000001 월드 단위 미만이었다.
- 위/아래 Game View 캡처: `LocalTools/Analysis/aim90-up.png`, `LocalTools/Analysis/aim90-down.png`.
- 수직 조준 시 총/팔과 머리/몸통의 시각적 겹침은 사용자 확인이 필요하다. 움직이는 상태의 전체 각도 시각 검증은 아직 완료하지 않았다.
- 횡스크롤 시험 맵 재생성 시에도 90도 제한이 적용되도록 빌더에 설정했다.

## 위 조준 추가 조정

- 50도 초과에서 총/손은 머리 앞, 가까운 팔은 총 앞에 표시한다. 낮은 각도에서는 원래 순서를 복원한다.
- 얼굴을 피하기 위한 총 위치 이동은 사용자 피드백으로 제거했다.
- 머리 단독 후퇴(18 픽셀)와 추가 턱 회전은 목 이탈 피드백으로 제거했다.
- 대신 55~90도에서 연결된 상반신 전체를 허리 근처(Upper Body Alignment 로컬 y=0.9)를 축으로 0~8도 뒤로 기울인다. 총 조준은 기울어진 부모 좌표에서 다시 계산하고 양팔 IK를 푼다.
- 0/55/70/90/-90도 정지 시험에서 양팔 도달 가능, 접점 오차 0.000001 미만 확인. 수평 복귀 시 상반신 기울기 0 및 머리 기준 위치 복원 확인.
- 70도/90도 정지 화면 확인 완료. 90도에서는 얼굴 가림이 여전히 일부 남는다. 수평 조준 복귀 시 머리 기준 위치 복원 확인 완료.
- 아래 조준과 하체 이미지/동작은 변경하지 않았다.

## 아래 조준 1차 조정

### 현재 시험 상태

- 최신 자세 시험: 지상 -35~-55도에서 허리 축으로 상체/허리 의상을 0~6도 앞으로 숙인다. 머리 단독 이동은 없다. `groundedDownLean`으로 최대 기울기 조절 가능.
- 총의 지상 제한은 몸통 상대 각도가 아닌 실제 방향 -55도로 유지한다. 상체 회전에 따라 조준을 다시 계산한다.
- 정지 시험 -35/-45/-55도에서 양팔 도달 가능, 접점 오차 0.000001 미만 확인. 이미지 `LocalTools/Analysis/ground-down55-lean6.png`. 걷기/달리기의 손-무릎 겹침은 추가 사용자 확인 필요.

- 최종 지상 하단 제한은 -55도로 복귀했다. -60도는 사용자 화면에서 받치는 손과 무릎 보호대 겹침이 확인되어 기각했다. 접점 도달 가능 검사만으로 신체/장갑 관통을 검증할 수 없다는 점에 주의한다.

- 최신 비교 시험: 지상 하단 제한을 -55도에서 -60도로 5도 확장했다. 다른 자세/총 위치 보정은 변경하지 않았다. -55도는 이전 비교 기준으로 남긴다.
- 정지 -60도에서 양팔 도달 가능 및 접점 유지 확인. `LocalTools/Analysis/ground-down60-trial.png`에 화면 기록. 이동 중 손목/골반 겹침은 사용자 평가 필요.

- 최신 사용자 요청 반영: 지상 아래 조준 제한 -55도. 선 표시는 제거하고 X만 유지한다.
- X는 총구에서 실제 총 방향으로 `aimHitMask` 범위의 비트리거 Collider2D 첫 충돌점에 표시한다. 자기 캐릭터의 콜라이더는 제외한다. 충돌이 없으면 `previewAimRange` 끝점에 표시한다.
- 현재는 직선/즉시 충돌 기준 예측이다. 실제 탄환의 크기, 중력, 관통, 사거리 규칙이 추가되면 그 규칙과 동일한 검사를 공유해야 한다.

- 최신 규칙: 지상 아래 조준은 -45도 제한, 위는 +90도 유지. 지상에서는 아래 조준 총 위치 경로와 받치는 팔뚝 전면 표시를 사용하지 않는다.
- 공중에서만 깊은 아래 조준을 허용한다. 공중 전용 팔/손 및 점프 이미지는 아직 제작/적용하지 않았으며, 현재는 기존 파츠의 임시 자세이다.
- 실제 총 방향의 조준 표시를 추가했다. 제한으로 커서를 향할 수 없을 때 황색으로 표시한다.
- 조준 표시는 총구부터 설정 사거리까지의 선과 끝점 X로 변경했다. `previewAimRange`는 현재 시각 검증용 사거리(기본 3 월드 단위)이며, 실제 탄환 사거리와 장애물 충돌은 아직 연결하지 않았다.
- 사용자 검토 요청: 현재 지상 -45도 자세에서 조금 더 아래 각도까지 가능해 보인다. -50/-55도를 양팔/손목/몸통 겹침 기준으로 차후 비교할 것. 현재 제한은 -45도로 유지한다.

- 최신: 원본 파츠를 사용한 각도별 총 위치 경로 시험. -45도 기준 위치, -60도 (0.10, 0), -75도 (0.225, 0.025), -90도 (0.45, 0.075) 오프셋을 구간별 SmoothStep으로 연결한다. 아래 이전 오프셋 기록을 대체한다.
- 받치는 팔뚝은 새 위치 경로와 함께 -55도 아래에서 순서 15, 나머지는 기존 순서 9로 복원한다. 윗팔 순서는 8 유지.
- -90도에서 받치는 팔의 다리 겹침은 줄지만 방아쇠 손목 꺾임은 아직 크다. 이 경로는 완성본이 아닌 사용자 비교용 시험 상태이다.
- 이미지: `LocalTools/Analysis/down90-position-path-study.png`.

- 총 위치 오프셋은 아래 조준 최대 (0.02, -0.02) 월드 단위. 이전 오프셋 시험들은 이 값으로 대체했다.
- -45도보다 아래에서 받치는 팔뚝만 표시 순서 9에서 15로 올린다. 윗팔은 몸통 뒤에 유지하고 팔뚝은 몸통/골반 앞, 총/손 뒤에 배치한다.
- 수평/위 조준으로 복귀하면 팔뚝 순서 9 복원. 정지 상태 -60/-75/-90도 양손 접점 유지 확인.
- 이미지: `LocalTools/Analysis/down-support-forearm-front.png`. 팔뚝이 가려지던 문제를 분리하는 시험이며, 손목 자세 및 이동 중 시각 검증은 아직 완료하지 않았다.

- -45도 아래에서 총/손의 기준 위치를 몸 앞쪽으로 부드럽게 이동한다. -90도 최대 이동량은 0.22 월드 단위이다.
- 이동 이후의 어깨-목표 거리로 총 방향을 다시 계산하고 양팔 IK를 푼다. 머리/몸통의 아래 조준 자세와 하체는 그대로 유지한다.
- -45/-60/-75/-90도 및 수평/위 조준 복귀에서 양팔 도달 가능, 접점 오차 0.000001 미만 확인.
- 정지 상태의 아래 90도 화면: `LocalTools/Analysis/aim90-down-forward.png`. 팔꿈치 자세의 미적 판단과 이동 중 검증은 사용자 확인이 필요하다.
