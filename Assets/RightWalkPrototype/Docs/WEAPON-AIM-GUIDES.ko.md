# 특수탄 조준 안내 / 선택 잔량 단순화 — 2026-10-23

사용자 승인 범위: 선택 안내에서 네모 테두리·최대량을 제거하고 S 6 / R 2 / G 3처럼 표시. 샷건 범위와 관통 라이플 안내선을 추가한다. 이번에 무기 피해/탄속/탄약 정책·네트워크 연결 방식을 변경하지 않는다.

## 표시

- 본인만 우클릭으로 실제 특수탄 모드에 진입했을 때 표시한다. Q/E 사전 선택만 한 상태와 일반탄·유탄에는 새 선을 표시하지 않는다. 유탄은 기존 예상 포물선을 계속 사용한다.
- 샷건은 ShotgunRange=5, ShotgunSpread=12도에서 25개 표본으로 외곽선을 그린다. 양 끝과 도달 경계만 얇게 표시하며 영역을 채우지 않는다. 모든 부채꼴 내부가 피해를 받는다는 의미가 아니라 서버 산탄/랜덤 퍼짐이 도달할 수 있는 최대 외곽이다.
- 가시 경계는 실제 FireSpreadServer와 같은 총구 뒤 barrel-back 검사, TraceShot의 고체/단방향 발판 예외와 플레이어 ServerHitBounds를 사용해 차단점까지 줄어든다. UI에서 계산한 결과를 서버에 보내지 않는다. 실제 발사 판정은 기존 서버 코드 그대로다.
- 라이플은 현재 총구/실제 조준 방향에서 RifleRange=30까지 얇은 보라 선을 그리며 벽·플레이어를 만나도 끊지 않는다. 비행 속도가 있는 탄환의 예상 경로이며 즉시 명중 판정으로 바꾼 것이 아니다.
- 고갈은 빨강, 실제 교체·탄종별 재발사 대기 중은 흐린 주황으로 표시한다. 라이플 대기는 점선, 샷건 대기는 경계 교대 표본으로 구분한다.
- 메뉴/전체맵/대기→전투 전환·카운트다운/사망/결과·대기방 UI 위 포인터는 숨긴다. 기존 aim.showAimPreview 및 소유자 제한도 사용한다. 추가 NetworkVariable/RPC는 없다.
- 머리 위 선택 안내는 테두리/배경 없이 작은 그림자와 탄종색의 문자+현재 잔량만 표시한다. 0발이면 문자와 숫자 모두 빨강. 1.4초/마지막.25초 페이드·본인 전용·선택 보존은 유지한다. 고정 HUD의 선택 탄종도 현재 잔량만 표시하며 전체 보유량 목록의 최대량은 유지한다.

## 원본

Scripts/SideScrollNetworkPlayer.WeaponGuides.cs가 실제 표시/경계 계산을 담당하고 RightFacingAimRig.OnGUI의 기존 특수탄 끝점 표식을 대체한다. SideScrollNetworkPlayer.AmmoSelectionHint.cs가 문자+숫자를 담당한다. Editor의 Verify Weapon Aim Guides는 이 검사에 한해 기존 오프라인 혼자연습 경로를 사용한다.
