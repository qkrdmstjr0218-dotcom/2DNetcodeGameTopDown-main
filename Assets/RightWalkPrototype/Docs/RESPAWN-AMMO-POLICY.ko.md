# 경기 시작·부활 탄약 정책

2026-10-22 사용자 의견 반영.

- 새 경기 시작은 일반탄/모든 특수탄 만량.
- 같은 경기 안 자동 부활은 사망 직전 특수탄 잔량을 그대로 유지한다. 빈 특수탄은 빈 상태로 유지하며 사망이 보급을 대체하지 않는다.
- 사용자 후속 요청으로 일반탄은 부활 시 만량 충전한다. 특수탄만 사망 직전 잔량을 유지한다. 일반탄의 평상시 자동충전은 그대로다.
- 체력/스태미나/새 생명·위치와 발사 대기 초기화는 유지한다. 보호막은 새 생명에 이월하지 않는다.
- 대기방 복귀는 기존대로 연습용 만량 복구/자동 보충. 그다음 새 경기도 만량으로 시작한다.
- 옛 RoomFlow 없는 수동 부활 시험 경로는 변경하지 않는다.

SideScrollNetworkPlayer의 자동 부활만 ResetArenaLife(false)를 호출한다. 기존 ResetForArenaRound()는 ResetArenaLife(true)를 호출하므로 경기 시작·대기 복귀 및 기존 검사 도구의 명시적 초기화는 보존된다.

Verify Respawn Ammunition: 호스트/참가자의 서로 다른 빈/부분 탄약을 사망·자동부활·반복 사망에 걸쳐 확인하고, 새 경기/대기 복귀는 만량인지 검사한다. 일반탄 보유량 확인 중에는 검사에서만 재충전 속도를0으로 고정하고 원래 속도로 되돌려 충전 재개도 확인한다.
