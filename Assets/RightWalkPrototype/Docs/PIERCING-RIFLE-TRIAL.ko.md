# 관통 라이플 시안 · 2026-10-21

Q/E로 일반탄·샷건·관통 라이플을 순환하고, 우클릭을 유지하며 좌클릭하면 선택 특수탄을 쏜다. 우클릭 해제 시 일반탄이다. 고갈된 특수탄은 우클릭 유지 중 발사가 차단되고 붉은 고갈 표시를 보이며 일반탄으로 자동 전환하지 않는다. 현재 RoomFlow arena에서만 사용하며 기존 씬/비행 샷건은 유지한다.

## 시험 규칙
- 사거리30, 탄속48, 간격1.2초, 탄약3발. 플레이어 피해50, 적/옛 표적은 체력 단위에 맞춰4피해다. 차징/헤드샷/거리·지형 감쇠/관통 수 제한은 없다.
- 벽·바닥·엄폐물·맵 경계를 통과해 사거리 끝까지 날아간다. 서버가 프레임마다 지나간 구간과 현재 대상 bounds를 검사하며, 발사 때 명중 대상을 미리 고정하지 않는다.
- 플레이어/적/표적을 여러 명 관통하지만 각 대상은 한 발당1회만 피해를 받는다. 발사자 본인은 제외한다. 지형은 멈춤 조건이 아니며 대상 뒤에도 계속 진행한다.
- 서버가 소유권·생명 세대·발사 원점/방향·잔량·탄종별 사격 간격·교체 지연·경기 상태를 검사한다. 라운드 변경/종료/연결 해제 시 진행 중 피해를 중단한다. 각 탄종의 대기시간은 교체 후에도 유지되지만, 다른 탄종의 대기시간까지 강제하지 않는다. Q/E 선택 변경/우클릭 실제 탄종 전환은0.18초 지연한다.
- 각 화면은 서버 시작시각과 같은 속도로 보라빛 탄환/보라색 꼬리(초기 굵기의1.5배)를 표시한다. 실제 피해 순간의 불꽃도 서버가 알린다. 넉백은 추가하지 않았다.
- 시작/부활/새 경기/대기 복귀3발, 대기방에서만 사격 중단2초 후2초당1발 보충. 기존 상자/적의 샷건 드롭은 변경하지 않았으며 라이플 탄약 드롭은 후속이다.

설정 원본은 SideScrollNetworkPlayer.Rifle.cs의 RifleCapacity/Damage/TargetDamage/Range/Speed/Interval 상수다. 서버 판정·시각 이동·로컬 입력·HUD가 같은 값을 사용한다. 조준 사거리 표시도 라이플 활성 중에는 지형에 멈추지 않는다. 기존 즉발 샷건 표시 역시 실제 활성 탄종을 기준으로 사거리5를 사용하도록 맞췄다.

FPSbasic 적 도입은 이번 범위가 아니다. 포탑/드론/큰 새 맵/수류탄/회복 등은 후속이다.

검증: LocalTools/Analysis/NetworkCombat/room-033554/result.txt 4인 PASS. 동일 폴더 piercing-rifle.png에서 발사 효과와 HUD 확인. Tools/Right Walk Prototype/Verify Piercing Rifle로 집중 검사 가능.

## 2026-10-21 전환/조준점 후속
