# 보급·스폰 후속 피드백 (2026-10-22)

사용자 마지막 발언은 확인 내용/아이디어 기록이다. 이 문서 작성과 코드 확인만 진행하며 게임 코드·씬·재생 상태를 변경하지 않는다.

## 다음 수정 요구/검토

1. 플레이어 시작/부활 지점이 가깝고 바로 서로 사격 가능한 문제 검토. 첨부 첫 화면의 같은 측면 상하 스폰도 포함한다. 단순 거리뿐 아니라 초기 시야/사선·이동 동선을 확인해야 한다. 아직 스폰 좌표 변경/무적 도입은 결정하지 않았다.
2. 탄약 아이템 위 R+1/S+3 등의 수량 문구 제거 희망. 탄약 아이템 지급량도 출처와 관계없이 동일하게 할 필요가 있다는 의견. 기존 적 드롭1발과 고정 공급3발의 차이를 정리하며, 일반 회복25·보호막50을 탄약1과 혼동하지 않는다. 통일 수치 최종 구현은 후속.
3. 탄약 드롭이 바닥을 조금 파고드는 현상. 현재 공통 안착 중심 높이는 바닥+.3, 탄약 테두리 반높이는 약.36이므로 시각적으로 겹칠 수 있다. 외형 반높이와 부유 흔들림을 고려해 실제 지면 위에 놓이도록 보완 필요. 다른 경사/가동 다리 위도 확인 대상이다.
4. 맵 곳곳에 남은 옛 고정 샷건 보급 위치 정리. 중앙 보급고는 현재 샷건 하나뿐이며 S/R/G 공급으로 전환 검토. 사용자는 중앙 공급 아이템 수/공간 확대도 제안했다. 여러 개를 주는 것과 한 아이템의 지급량 증가를 구분한다.
5. 경기 시작 때 특수탄 만량 지급은 사용자가 의도하지 않았다. 경기 시작 시 특수탄 없이 보급을 통해 확보하는 정책으로 조정 필요. 대기 연습 자동 보충/부활/대기 복귀 잔량 정책은 구분하여 정해야 하며 이번 기록에서 전부0으로 변경하지 않는다.
6. 유탄이 보호막 드론을 더 효과적으로 파괴하도록 조정 희망. 현재 적 대상 거리 피해는 이미 중심3→가장자리1이다. 보호막 드론 체력12 대비 중심 폭발4회가 필요하여 유탄 기본3발로 단독 파괴가 어렵다. 기존 거리 함수를 유지하면서 적 공통 피해 또는 보호막 드론 대상 피해 수치를 조정할 수 있다. 구체 수치는 미결정이다.
7. 해킹 지점 순서가 무작위인지 질문. 현재 시작 Point=0, 이후 (Point+1)%지점 수로 고정 순환한다. 무작위 선정/연속 중복 방지/예고할 다음 지점의 서버 확정은 후속 검토다.
8. 보호막 드론 무작위 여부 질문. 현재 첫10~16초/이후25~40초 무작위, 좌우 방향과 비행 후보 높이 시작을 무작위 선택한다. 실제 경로는 지형을 통과할 수 있는 비행 그래프로 제한하며 완전 임의 좌표 스폰이 아니다.
9. 적의 갑작스러운 생성/재생성은 대응하기 어렵다는 피드백. 등장 예고/출현 연출 검토. 지상 출입구·바닥 출현 포탑·비행 진입 등 과거 후보와 연결할 수 있으나 아직 이번에 새 규칙을 구현하지 않았다.
