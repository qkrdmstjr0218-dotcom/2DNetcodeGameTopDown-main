**현재 상태:** 사용자 승인으로 현재 게임의 기본 샷건에 채택했다. Q/E는 일반탄과 새 샷건 두 종이며 시험 명칭/분리 표시를 제거했다. 보급과 적 드롭도 새 잔량을 채운다. 아래 독립 비교 설명은 채택 이전 기록이다. 비행 샷건 코드는 옛 시험 씬용으로 보존하고 현재 게임의 구형 RPC는 차단한다.

기존 비행 샷건을 보존하고 별도 선택 탄종 `즉발 샷건(시험)`을 추가했다. 현재 arena RoomFlow에서만 선택 가능하다.

- Q/E로 일반탄 → 샷건 → 즉발 샷건을 순환 선택한다(Q는 반대 방향). 우클릭을 유지하며 좌클릭하면 선택 특수탄, 우클릭 해제/고갈은 일반탄이다.

- 즉발판도 각 산탄의 최초 지형/표적에서 멈추며 엄폐를 관통하지 않는다. 부채꼴 전체의 모든 대상에게 피해를 주는 별도 범위 공격은 아니다.
- 총구~각 명중점 전체 선을 즉시 켜고 .09초 동안 지운다. 총구 섬광과 착탄 불꽃도 동시에 표시한다. 비행 탄환 애니메이션은 없다.
- 기존 샷건6발과 독립된 비교용6발이다. 현재 HUD에 두 잔량을 나란히 두고 즉발 선택 링은 주황색이다. 새 생명/경기/대기 복귀에 전량 초기화, 대기방에서만 중단2초 후2초당1발 보충한다. 경기 중 기존 보급/적 드롭은 원래 샷건만 채운다. 새 보급 아이템을 추가하지 않았다.
