- 머리 분리/다리 가장자리/정면 하이라이트 셰이더에는 선택적 RGB 샘플 교체만 추가했다. 기존 클리핑·알파·하이라이트 조절은 유지한다. 일반 스프라이트는 호환 unlit sprite pass를 사용하며 원래 색/투명도 값을 보존한다. 런타임 생성 사망 스프라이트의 URP 기본 머티리얼도 이 경로로 처리한다. 현재 맵의 전역 조명 기준 화면을 확인했으며 별도 동적 2D 조명 환경의 등가성은 검증하지 않았다.
- 측면 다리의 실제 표시 메시와 정면 이동 다리는 원본 텍스처가 머티리얼이 아닌 MaterialPropertyBlock의 `_MainTex`에 있다. 해당 값을 우선 읽고 기존 블록의 텍스처/색을 보존한다.
