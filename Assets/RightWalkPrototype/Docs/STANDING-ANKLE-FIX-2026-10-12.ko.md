# 정지 자세 발목 연결 보정

푸른 윤곽 보정의 거친 경계 후속 수정: 색상 임계값의 경계를 바로 검게 덮는 대신, 발목 제한 영역 안에서 마스크를 1px 확장하고 0.65px Gaussian feather로 원래 색과 혼합한다. 자세, 원본 파츠, 외곽 알파 및 달리기는 유지한다.

하늘색 점 재확인: 원본 부츠를 배경색 위에 확대해 해당 부츠 그림에 하늘색 픽셀이 없는 것을 확인했다. 현재 걷기 합성 시 발목 끝의 제한 영역에서 강한 푸른색 윤곽 픽셀을 검은 연결부 색으로 바꾸는 처리를 추가했다. 승인 원본과 달리기 시트는 수정하지 않는다. 이전 알파 구멍 수리는 사용자 지적의 점을 제거하지 못했다.

하늘색 점 후속 확인: 발목 주변에서 외부 배경과 연결되지 않은 작은 알파 구멍을 검사해 총 16픽셀을 인접 파츠 색으로 메웠다. 외곽선에 열린 틈이나 원본의 푸른 명암은 이 검사에서 변경하지 않는다. 사용자 스크린샷의 해당 점과 일치하는지는 실행 화면에서 추가 확인이 필요하다.

## 전체 걷기 주기 후속 보정

사용자 움직임 검사에서 정지 자세 외의 이탈이 확인되어, 아래의 정지 위상별 보정은 현재 폐기했다. 현재 생성기는 40프레임 x 2다리 모두를 검사한다. 종아리 원본 끝에서 축 방향 28px 이내의 불투명 픽셀을 신발 알파와 비교하고, 고정 길이 IK 목표와 신발 가로 배치를 제한 범위에서 탐색해 노출을 줄인다. 밑창 높이와 회전, 원본 파츠 및 달리기 시트는 변경하지 않는다.

80개 연결의 검사 영역 내 노출 픽셀은 평균 2.925, 최대 77이다. 완전한 이탈 제거 판정은 아니며, 이는 해당 영역의 마스크 비교 결과이고 모든 발목 윤곽 검사와 동일하지 않다. 정지 자세 확대에서 이전 검은 장갑 돌출과 흰 끝 이탈이 줄어든 것을 확인했다. 보정 위치 변화에 따른 걷기 흔들림은 사용자 실행 확인이 추가로 필요하다.

정지 시 사용하는 WalkStrideTrial의 0번과 20번 프레임을 보정했다. 최초의 양쪽 공통 왼쪽 10px 보정은 한쪽 발목 장갑의 뒤쪽 돌출을 악화시켜 폐기했다. 현재 0번 앞쪽 종아리는 오른쪽 10px/위쪽 2px, 뒤쪽 종아리는 왼쪽 10px로 보정한다. 20번에서는 앞쪽 파츠를 쓰는 뒤에 선 다리는 원래 위치를 유지하고, 뒤쪽 파츠를 쓰는 앞에 선 다리는 오른쪽 10px/위쪽 2px로 보정하면서 해당 신발을 오른쪽 12px 옮긴다. 신발 회전과 밑창 높이는 유지한다. 다리 길이는 그대로 유지하며 무릎을 고정 길이 IK로 다시 계산한다. 원본 파츠를 자르거나 늘리지 않았다.

정지 위상에서 0.1 주기 이내의 주변 프레임에도 부드럽게 감소하는 보정을 적용했다. 나머지 위상에는 보정이 없다. 걷기 속도, 보폭, 골반 주기 및 달리기 시트는 변경하지 않았다. 현재 이 걷기 시트를 공유하는 시험 씬들에도 적용된다.

40프레임 생성 도달 불가 0, 최대 관절 길이 오차 7.11e-14px. 두 정지 자세의 확대 이미지를 확인했다. Unity 검사에서 연결 도구의 5초 타임아웃이 한 차례 발생해 재시도했다. 사용자 시각 확인 전 보정본이다.

재생성: LocalTools/Analysis/bake_stride_trial.py.
확대 확인: LocalTools/Analysis/inspect_standing_ankles.py 및 standing-ankle-detail.png.

양쪽 파츠와 두 정지 자세를 따로 비교한 도구는 LocalTools/Analysis/calibrate_standing.py다. 수정 후 확대 이미지에서도 20번 뒤쪽 파츠의 흰 끝과 검은 장갑 윤곽은 추가 확인이 필요하다. 완벽한 연결로 판정하지 않는다.
