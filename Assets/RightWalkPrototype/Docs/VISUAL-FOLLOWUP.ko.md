# 픽업·지원 드론·돌진 예고·전환 UI 후속 (2026-10-25)

## 사용자 피드백 반영

- 회복/보호막 월드 픽업의 ‘회복 +25’, ‘보호막 +50’ 문구를 제거했다. 녹색 십자/파란 방패와 정사각 금속 프레임만 표시한다. 캐릭터 머리 위/좌상단의 실제 HP와 보호막 잔량 숫자는 유지한다.
- 기존 회복/보호막의 표시 외곽 약.7×.525를.7×.7로 바꿨다. 바닥 침투를 피하도록 표시 중심을.1 올렸고, 서버 몸 접촉 검사도 같은 중심·크기·기존 흔들림을 사용한다. 기존.025 몸 여유/만량 거절/서버 단일 지급은 유지한다. 회복25/보호막50 및 수급·만료 수치는 바꾸지 않았다.
- 현재 득점 중인 해킹 구역은 실제 다음 구역 교체가 남은3초 이내일 때 테두리/면/단말기/마름모의 밝기가 변한다. 구역은 완전히 사라지지 않는다. 경기 종료가 교체보다 먼저 오면 점멸하지 않는다. 공유된 경기 시계를 사용하며 위치/점령 판정/득점/교체 시간은 불변이다.
- 지원 드론은 회백색 기체와 양쪽 로터, 얇은 연결대, 파란 방패 문양이 있는 하부 화물로 구성했다. 포신은 없다. 비행/충돌.85×.9 offset.48/보호막 보상/격추 점수 규칙은 그대로다.
- 지상 적의 독립된 화살표를 차체 앞쪽에 달린 장전 발광부로 대체했다. 돌진 준비 중 황색 점멸, 돌진 중 밝은 따뜻한 색으로 변한다. 차체 좌우 반전과 함께 움직이며, 돌진 방향·거리·속도·피해를 바꾸지 않는다.
- 전장 진입/대기방 복귀/참가자 도착 대기/카운트다운/전투 개시/로비 연결 중 표시를 공통 계기판 프레임과 진행 신호로 통일했다. 연결 중 표시는 실제 진행률을 뜻하지 않는 순환 표시다. 기존 도착 확인/서버 시간/조준만 허용하는 카운트다운/이동·사격 차단 규칙을 유지한다.

## 아트·재현

`LocalTools/ArtReviews/AppliedFoundryArt/build_visual_followup.cjs`는 수작업 SVG에서 SupportHull/SupportCargo/GroundCharge 및 사각 Pickup_Health/Shield를 PNG로 출력한다. `build_pickups.cjs`는 마지막에 이 후속 생성기를 기다려 실행하므로 이전 아이콘으로 되돌리지 않는다. FoundryArtBuilder.ImportTextures로256PPU·Sprite·보간·비압축 설정을 맞춘다. 외부 생성형AI/새 이미지 플러그인은 사용하지 않았다.

이번 요소에는 흰 금속/청회색 음영/작은 황동 장식을 사용했다. 플레이어와 전체 맵의 화풍 차이를 모두 해결한 작업은 아니며, 기존 플레이어 원본이나 전체 배경을 교체하지 않았다. 소리 설정/음원은 변경하지 않았다.

## 검사와 발견한 문제

ArenaVisualFollowupReview 단일 Editor solo로 실제 시작→카운트다운→경기→결과→복귀를 거쳤다. 아트 캡처 구간만 match.Update를 정지하고 독립된 실제 ArenaPatrolEnemy 표시 컴포넌트/픽업/점령 상태 fixture를 사용한다. 따라서 해당 드론 사진은 자연 비행/실제 격추 검증이 아니다. 로비 연결 중 표시는 OnlineBusy만 잠시 바꾼 표시 fixture로 인터넷 요청을 보내지 않았다.

지원 기체/화물·무기 없음/기존 충돌 크기·돌진 예고의 앞면 반전/비활성·활성·돌진 색·아이템 문구 없음/실제 알파 영역 사각 외곽·교체 예고와 구역 판정 불변·일반 시간/종료 우선 점멸 거절을 확인했다. 자료는 LocalTools/Analysis/VisualFollowup/result.txt 및 같은 폴더 PNG다.

첫 픽업 크기 검사는 투명 여백을 포함한 Sprite.bounds를 비교해 실패했다. PNG 알파 영역을 측정하도록 검사 방법을 수정했다. 초기 사진에서 픽업은 기존 보급품과 겹쳐 있어 분리 배치했다. 지원 기체가 공유 셰이더에서 표시되지 않는 문제는 별도 카메라의 새 재질/기본 재질 비교와 실제 화면으로 확인했다. ArenaEnemyArt는 이제 각 SpriteRenderer의 MaterialPropertyBlock에 자신의 _MainTex를 명시해 부품 텍스처를 바인딩한다. 수정 후 실제 게임 캡처에 기체와 화물이 모두 표시된다.

실제 멀티/배포 빌드/전체 자연 비행 전투/전체 맵 화풍 통일은 이번 검증 범위가 아니다.
