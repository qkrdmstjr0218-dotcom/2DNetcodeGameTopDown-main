# 점프 스프라이트 제작 기준

## 현재 상태

- 상승 시안은 자세 방향을 승인받았으며, 아직 게임 프레임으로 적용하지 않았다.
- 정점·하강 시안은 참고용이다. 무릎 장식 중복과 기존 시트 대비 비율 차이를 수정해야 한다.
- 생성된 전신 시안을 그대로 자르거나 덧씌우지 않는다.
- 기존 AirDownShotPose의 달리기 프레임 대체는 임시 처리이며 일반 점프의 기준이 아니다.

## 원본 기준

- 실제 보행: WalkStrideTrial.png / WalkStrideTrialFrames.asset.
- 실제 달리기: RunRecoveryTrial.png / RunRecoveryTrialFrames.asset.
- 각 타일 512 x 512, Pixels Per Unit 204.8, pivot (0.5, 0.025).
- 보행 시트는 5열 x 8행의 40프레임이다. 점프 프레임 수를 보행에 맞춰 억지로 늘리지 않는다.
- 파츠 배치 기준은 RightWalkSheetBuilder 및 실제 SideScrollNetworkPlayer.prefab이다.
- 기존 머리, 몸통, 허리 의상, 팔, 총과 그립 기준점은 재사용한다.
- 다리 시트에는 골반/허리 일부가 포함돼 있다. 단순히 다리 아래만 잘라 교체하면 연결이 어긋날 수 있다.

## 변경하지 않을 것

- 허벅지·종아리 길이, 신발 크기, 캐릭터 체형과 측면 시점.
- 장식의 개수와 소속: 무릎 장식을 추가 관절처럼 복제하지 않는다.
- 승인된 종아리의 단일 선, 선 굵기, 장식 복구 상태.
- 흰 갑옷과 검은 연결부의 면적, 금색 장식 색, 외곽선과 명암 스타일.
- 타일 크기, PPU, pivot, 골반 연결 좌표. 이미지 외곽을 기준으로 프레임마다 자동 중앙 정렬하지 않는다.
- 점프를 위해 총·손·머리를 새 전신 그림으로 교체하지 않는다.

## 제작 순서

1. 기존 양발 지지 프레임과 승인된 상승 시안을 나란히 비교한다.
2. 기존 다리 디자인을 유지한 상승 키프레임을 동일 좌표계로 제작한다.
3. 상승 프레임을 기준으로 정점·하강 키프레임을 수정한다. 새 전신 생성으로 매번 다시 시작하지 않는다.
4. 착지 압축과 회복 프레임을 추가해 기존 양발 지지 자세로 연결한다.
5. 같은 상반신을 합성한 비교 시트와 짧은 반복 애니메이션으로 검증한다.
6. 검증한 프레임만 별도 점프 시트로 저장하고 런타임·네트워크에 연결한다.

## 동작 연결

- 서기/걷기/달리기에서 점프 시 보행 위상을 억지로 되감지 않는다.
- 이륙 직전의 좌우 발 위치에서 상승 자세로 이어지는 전환 프레임을 검토한다.
- 상승: 허벅지는 아래, 무릎은 적당히 굽히고 발은 골반보다 충분히 낮게 둔다.
- 정점: 상승보다 무릎을 조금 펴고 두 발을 몸 아래로 내린다.
- 하강: 발이 착지에 대비하되 무릎을 완전히 잠그지 않는다.
- 착지: 발바닥은 지면에 두고 무릎과 골반을 잠깐 낮춘다. 이미지 전체를 지면 아래로 내리지 않는다.
- 이동 중 착지는 짧은 압축 후 현재 이동 방향/속도의 보행 또는 달리기로 복귀한다.
- 정지 착지는 양발 지지 자세로 복귀한다. 입력과 물리 이동을 착지 애니메이션 종료까지 막지 않는다.
- 상태 전환은 시간만이 아니라 Grounded와 수직 속도를 기준으로 한다. 정점 부근에는 전환 여유를 둔다.
- 물리 캐릭터 이동과 그림의 골반/다리 보정은 분리한다. 시트에 점프 이동 거리를 구워 넣지 않는다.
- 공중 하단 사격은 일반 점프가 안정된 뒤 별도 자세로 다룬다.

## 완료 판정

- 정지 점프, 걷기 점프, 달리기 점프 각각 좌우에서 확인한다.
- 같은 골반 위치에 겹쳐 비교해 프레임 변경 시 체형·신발 크기·허리 접합이 튀지 않는지 확인한다.
- 상승/정점/하강/착지에서 발목 분리, 갑옷 관통, 선 끊김, 중복 장식이 없는지 확인한다.
- 바닥뿐 아니라 플랫폼 위 착지도 확인한다.
- 상하 조준 중에도 머리·목·허리·팔과 총 그립이 유지되는지 확인한다.
- 로컬 적용 후 네트워크에 점프 상태와 프레임을 전달한다. 현재 보행 frame/running만으로는 전용 점프를 재현할 수 없다.
- 두 클라이언트에서 같은 점프 상태와 착지 복귀를 확인하기 전에는 네트워크 완료로 표시하지 않는다.

이 문서는 제작 기준 정리이며, 일관성이 확보된 점프 시트나 런타임 적용이 완료됐다는 뜻은 아니다.
