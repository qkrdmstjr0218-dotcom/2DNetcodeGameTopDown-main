# 정면 정지 하단 사격 비교 씬

- 씬: `Assets/RightWalkPrototype/SideScrollFrontStandingReview.unity`
- Play하면 오른쪽/왼쪽 각각 측면 → 정면 하단 -55° → 수직 하단 -90°를 1.2초 간격으로 반복한다.
- 게임 화면 오른쪽 위 버튼으로 측면·하단을 고정하거나 `마우스 조준`으로 돌아간다. `자동 연속 비교`로 반복을 재개한다.
- 이동/점프는 기존 A/D·방향키/Space를 사용한다. 정면은 기존 시험과 같이 수평 이동 중 해제된다. 공중 하단 사격의 완성 자세를 검증한 씬은 아니다.

## 비교 대상

- 원본 정면 몸과 다리 굵기·길이 및 무릎 위치를 보존했다.
- 허벅지 흰 타원 파츠의 위쪽 크기/위치를 늘려 허리 장비 뒤로 겹치게 했다.
- 하복부의 좌우 흰 조각과 가로 띠를 좁고 긴 흰 일체형 파츠로 정리했다.
- 기존 조각 수를 유지하며 치마형 장비를 키운 시안이다. 정확한 최종 크기는 미확정이다.
- 앞서 시험한 평평한 발바닥과 머리 균등 확대 1.08을 이 씬에 적용했다.
- 머리/총 크기 및 전환 순간의 위치·실루엣 정렬은 최종 승인 상태가 아니다. 숫자/검사 통과는 그림 승인과 다르다.

## 보존 범위

새 atlas/material과 별도 씬을 사용한다. 기존 `SideScrollFrontDownAimTrial.unity`, 원본 atlas 및 측면/네트워크 프리팹은 덮어쓰지 않았다. `FrontDownAimOverlay.headScale` 기본값은 1이고, 새 씬에서만 1.08이다. 머리 확대는 목 기준 균등 배율이며 전신 비선형 변형을 다시 넣지 않았다.

고해상도 생성 의상은 실제 atlas 몸 레이어에서 추출한 원본을 기준으로 했으며, 의상/발 영역만 합성했다. 해당 영역 밖 atlas 픽셀 변경 0을 확인했다. 생성 이미지 전체를 캐릭터로 교체한 것이 아니다.

검증/캡처: `LocalTools/Analysis/HomeVerification/StandingReview/`. 자동 전환 6자세, 몸 안쪽 커서 30곳(총구 뒤 18곳), 몸 밖 측면/상단 복귀 4곳을 확인했다.
