# 인터넷 로비·Relay 연결

2026-10-23 사용자 승인으로 이전 Relay 보류 방침을 해제했다. 현재 Foundry 씬의 로컬 전용 연결 화면에 인터넷 방 생성/목록/입장을 연결한다. 기존 템플릿 NetworkSessionLauncher 및 PlaygroundSessionUI는 변경하지 않는다.

## 사용 흐름

재생 → 로비 → 방 이름 입력/방 만들기 또는 새로고침/목록에서 입장 → 기존 소규모 대기방 → 준비/해제 → 방장 시작 → 전환/3초 카운트다운 → 경기 → 결과 → 같은 대기방 복귀.

방 목록은 방 이름/모드/맵/인원/대기·진행·결과 상태를 표시한다. 모드는 기존 해킹 구역 점령 하나, 맵은 주조 시설08,2~4명/3분이다. 진행 중/결과 확인 중/만석인 방은 입장 버튼을 비활성화한다. 입장 순간 상태가 바뀌면 서버 승인에서도 진행/만석/버전 불일치를 거절한다. 플레이어가 코드를 입력하지 않고 세션 목록의 ID로 참가한다.

처음 새로고침 후 로비에 있는 동안5초 주기로 목록을 갱신한다(최대30개, 페이지 이동은 후속). 방 만들기는 즉시 익명 인증과 Relay 할당을 진행한다. 접속 중 중복 작업을 막고 실패 메시지를 표시한다. 자동/수동 목록 요청 사이에는 최소1.5초를 두고, 오류 뒤에는3초를 기다린다. 조회 실패로 남은 이전 목록에서는 입장을 비활성화하여 오래된 상태를 최신으로 취급하지 않는다. 기존 같은-PC 로컬 연결은 Editor/Development Build의 접힌 개발 메뉴로 유지한다.

방장이 나가면 세션을 삭제하고 참가자는 로비로 돌아온다. 참가자가 나가면 본인 세션 참여를 정리한다. 경기 시작부터 결과/복귀 전까지 backend IsLocked=true로 잠그고, 대기방 복귀 후 해제한다. 결과→복귀 동안 방 ID는 유지한다. 방장 승계는 구현하지 않는다.

## 구현

설치된 Unity Multiplayer Services SDK2.3.3의 Sessions API를 사용한다. CreateSessionAsync(SessionOptions.WithRelayNetwork), QuerySessionsAsync, JoinSessionByIdAsync와 SDK의 네트워크 수명/하트비트를 사용하며 별도 Relay 코드를 UI나 직접 Lobby Data에 노출하지 않는다.

- SideScrollNetworkSession.Online.cs: 익명 인증/방 생성·조회·입장/퇴장·삭제/상태 갱신.
- SideScrollNetworkSession.LobbyUI.cs: 인터넷 로비 UI 및 입장 가능 상태.
- SideScrollNetworkSession.cs: 기존 NGO 프리팹/서버 생성·대기방 승인과 통합. StartLocal은 기존 직접 연결 유지.
- 호환 표식 OnlineRoomKind는 SessionProperty String1로 검색하고 NGO 접속 payload도 확인한다. 다른 템플릿/게임 버전의 방은 목록에 섞이지 않는다.
- Editor 가상 플레이어는 프로세스별 인증 프로필을 사용해 동일 익명 계정으로 중복 접속하지 않는다. 실제 빌드는 기기의 기존 기본 익명 프로필을 사용한다.
- 네트워크가 먼저 종료되고 Lobby 삭제 알림이 뒤늦게 도착하는 경우1.5초를 기다려 정상 종료와 오류 정리가 경합하지 않도록 한다.
- 서비스 오류는 한국어 문맥과 SDK 메시지로 표시한다. 방 목록은 서버의 최신 순간 상태를 보장하지 않으며 최종 승인도 함께 검사한다.

Unity 서비스 연결은 기존 프로젝트 설정을 사용하며 계정 키·토큰을 소스에 기록하지 않는다. 패키지 업그레이드/별도 서버/새 맵 로딩은 이번 범위가 아니다.

참고: [Unity 세션 생성](https://docs.unity.com/en-us/mps-sdk/create-session), [네트워크 연결 관리](https://docs.unity.com/en-us/mps-sdk/manage-session-network-connection), [세션 상태 갱신](https://docs.unity.com/en-us/mps-sdk/update-session-data). 실제 코드는 설치된2.3.3 API에 맞췄다.

## 혼자 연습 / 로컬 연결

로비의 `혼자 연습 · 인터넷 연결 불필요`는 loopback NGO 호스트만 시작한다. Unity Services 인증·방 목록·Relay를 호출하지 않는다. 준비 후 연습 시작으로 기존 실제 맵/적/점령/사망·부활/결과/대기 복귀까지 혼자 진행할 수 있다. 별도 단계별 안내 튜토리얼은 후속이며 현재는 연습 공간이다. 이 방에는 다른 참가자를 승인하지 않는다.

기존 개발용 로컬 방은 같은 PC의 여러 실행을 직접 연결하며2명 이상 시작 조건을 유지한다. 인터넷 방은 계속 Unity의 방 목록/Relay를 사용한다. 로비를 열기만 하거나 혼자 연습에 들어가는 것으로 인터넷 조회를 자동 시작하지 않는다(새로고침/인터넷 방 만들기에서 서비스 시작).
