# 특수탄 전용 Q/E 순환

2026-10-23 후속: 머리 위 안내는 이름 문구를 제거하고 탄약 아이템과 동일한 정사각형 테두리·S/R/G 이니셜만 표시한다(36px). 아이템과 안내가 ArenaObjectiveMatch.SupplyColor/SupplyInitial을 공유한다.1.4초 표시/마지막.25초 페이드/본인만 표시/HP·보호막 위 배치는 유지한다.

2026-10-22 사용자 승인. 현재 RoomFlow 모드에서 Q/E는 S 샷건 → R 관통 라이플 → G 유탄 → S로 순환한다. Q는 역순이다. 일반탄은 순환 대상에서 제외한다.

우클릭을 누르지 않은 상태의 좌클릭은 일반탄이다. Q/E로 특수탄을 미리 골라도 실제 발사 탄종이 일반탄이면 교체 대기를 새로 만들지 않는다. 우클릭을 유지하면 선택한 특수탄을 사용하고, 놓으면 일반탄으로 돌아오되 특수탄 선택은 기억한다. 빈 특수탄의 선택 유지/붉은 고갈 표시, 실제 탄종 교체.18초, 탄종별 재발사 대기는 유지한다.

HUD는 현재 발사 탄종과 '특수탄 선택'을 구분한다. 기존 useReadyRoom=false 씬의 옛 일반탄/샷건 선택 방식은 유지한다. SelectAmmo(Normal) API는 옛 씬/검사 호환을 위해 남지만 현재 게임 Q/E에서는 호출되지 않는다.

검증 메뉴: Verify Special Cycle and Expanded Enemies. 전후 양방향 순환, 우클릭 해제 일반탄 복귀, 사전 선택 시 일반탄 간격 유지, 실제 교체 지연 및 라이플 재발사 대기 유지, 참가자 선택을 확인한다.

사용자 후속 요청: 특수탄 선택 변경 시 본인 머리 위에1.4초 동안 탄종 색/이니셜/이름을 표시한다(S 노랑·R 보라·G 연두). 끝0.25초에 흐려진다. HP 위에 배치하고 보호막이 있으면 더 위로 올린다. 앉기 높이를 따르며 사망/생명 교체/전환/메뉴·종료에는 숨기고 다른 플레이어의 선택은 보여주지 않는다. 선택 자체는 표시가 사라져도 유지한다. 원본 SideScrollNetworkPlayer.AmmoSelectionHint.cs.
