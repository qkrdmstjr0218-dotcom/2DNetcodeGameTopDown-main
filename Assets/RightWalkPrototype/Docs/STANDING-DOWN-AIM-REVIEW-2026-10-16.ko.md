# 정지 하단 사격 자세 검토

- 목표: 반측면 지상 정지 하단 사격. 공중 하단 사격도 후속 목표이며, 발 수정만으로 충분한지는 아직 미확인.
- 허리의 치마형 장비와 허벅지 장비는 Unity에 적용된 기존 좌우 걷기의 위치·크기·좌우 소속을 기준으로 다시 비교해야 한다. 상당한 수정이 필요할 가능성을 기록하며, 세부 수치는 미확정이다.
- 생성 시안 `LocalTools/Analysis/HomeVerification/StanceCandidates/three-quarter-standing-v1.png`은 적용 불가. 오른다리가 앞으로 나오는 구도에서 왼허벅지의 방향과 뒤로 뻗은 왼종아리·발의 연결이 맞지 않고, 무릎 주변 장비가 겹쳐 좌우 다리가 섞여 보인다. 단순 발 접지 문제가 아니다.
- 해당 시안을 다음 편집의 기준 원본으로 삼지 않는다. 기존 Unity/브라우저 원본에서 각 다리의 골반→허벅지→무릎→발목→발 연결을 먼저 정하고, 의상·장비가 그 연결을 따르게 한다.
- 현재 생성 시안은 게임에 미적용. 기존 원화·총·상체·캐릭터 스케일 유지.
- 사용자 요청: 토큰 사용을 가능한 줄인다. 필요한 부위만 확인하고 중복 설명·불필요한 재생성을 피한다.

## 집 작업 후속 상태

- 생성 시안 v2에서 다리 혼합은 줄었다고 사용자 확인. 하복부 좌우 흰 장식·가로 띠 제거 후, 사용자 그림판 수정 형태를 참고한 좁고 긴 흰 일체형 파츠(v5)를 사용자가 일단 수용했다. 허리 장비·허벅지 흰 파츠 위치도 추가 조정 대상이다.
- v6은 허리 장비 확대 시 조각이 늘어났으며, 반복 생성에 따른 화질 저하로 게임 적용용에서 제외. 이후 작업은 고화질 원본 기준. 새 의상과 반측면 하체는 아직 브라우저/Unity 원본에 이식하지 않았다.
- 다리·발 첫 원본 재사용 시험: 기존 걷기 시트 `RightWalkSheet-Legs-FinalContour-v72.png`의 측면 신발을 UV 메시로 재사용하여 정면 원본 발목 아래에 배치했다. 다른 발이 끼어드는 부분은 다각형 UV로 제외. 양발은 기존 soleHeight와 같은 높이, 균등 배율이며 캐릭터 루트/콜라이더/카메라 설정은 저장 변경하지 않았다.
- 결과: `LocalTools/Analysis/HomeVerification/StanceCandidates/original-feet-trial-v3.png` 및 `original-feet-trial-v3-left.png`. 원본 정면 종아리와 측면 신발 사이의 시점·발목 연결은 미해결. 완성 자세나 적용 승인 상태가 아니다. 캡처에 보이는 원본 의상은 발 시험용이며 v5 의상 구상 철회가 아니다.
- 재현용 코드: 같은 폴더의 `original-feet-trial.csx` 실행 후 `original-feet-refine.csx`. 시험 씬 Play를 일시정지한 상태에서 실행하는 임시 도구이며, 정식 런타임 코드가 아니다. 시험 후 Play 종료로 원상 복귀했다.
- 사용자 피드백으로 위 신발 재사용 시험은 기각: 가운데 반측면 구도와 다르고, 연결이 절단·꺾인 형태다. 해당 시험을 후속 자세 기준으로 삼지 않는다.
- 대체 방향은 골반부터 발까지 이어지는 반측면 하체 신규 작화. 고화질 원본, 기존 측면 및 v5 의상 참고로 생성한 `three-quarter-lowerbody-redraw-v2.png`를 별도 저장했다. 접합 방식 대신 연속된 작화지만 양발 높이와 신발 시점 차이는 남음. 게임 미적용이며 사용자 수용 미확인.
- 중간 가이드와 다른 넓은/굽힌 자세라는 지적 이후 `guide-matched-lowerbody-v1.png`로 다리 벌림·무릎 굽힘을 줄였다. 이것도 확정 원화가 아니다.
- 사용자 재강조: 최우선은 기존 좌우 이동 원화와 머리/다리 등 부위 크기 및 바닥 접지를 맞추는 것. 정면 유지도 다시 후보로 언급했으나 확정 선택은 아니다. 허벅지 흰 타원 파츠는 윗부분이 허리 장비 뒤에 들어가 가려질 만큼 커야 한다.
- 같은 카메라로 새 하체를 원본 상체에 시험 조합했다. 첫 조합은 허리가 높고 다리가 길어 보여 하체 전체를 균등 축소해 허리 위치를 내렸다. 다음 `lowerbody-proportion-v2.png`는 무릎/종아리/신발 크기와 흰 허벅지 파츠의 위쪽 겹침을 조정한 후보이다.
- 현재 비교 자료: `proportions-comparison-v2.png` (왼쪽 기존 측면, 오른쪽 새 하체 임시 조합). 실제 크기에서는 머리 대비 하체의 굵기·크기, 상하체 스타일 및 허리 연결 문제가 남는다. 임시 검은 연결 도형이 포함된 비교용 조합이며 완성 원화/게임 적용 상태가 아니다. 루트/콜라이더/카메라 저장값은 그대로이며 Play 종료로 시험 변경은 복구했다.
- 최신 사용자 방향: 새 반측면 하체 후보는 종아리 길이·무릎 보호대 위치·복부 디자인·허리 장비 길이·허벅지 굵기가 모두 부적합. 원본 정면 하단 사격 구도로 돌아가 발 디자인의 바닥 접지와 기존 측면 대비 부위 크기(머리 확대 시험 포함)를 조정한다. 새 하체 후보를 확정 기준으로 쓰지 않는다.
- 허리가 심하게 가늘다는 지적은 폐기한 새 하체 시험 합성(`proportions-front-v2.png` 계열)에 대한 것이라고 사용자가 명확히 정정했다. 현재 원본 정면 허리를 넓히라는 지시로 해석하지 않는다. 위치·부위 크기는 전체 비교로 검토한다.
- 사용자는 Unity 조작을 계속 허용했다. 조작 시작/종료 시 알려서 사용자 조작과 겹치지 않게 한다. 시험 종료 후 Play를 종료하며 미저장 작업을 보존한다.
- 원본 정면 복귀 시험 결과: `original-front-head108-feet-v3.png`, 전후 비교 `original-front-before-after.png` (왼쪽 원본, 오른쪽 발 수정+머리 1.08). 원본 정면 몸통·허리·다리·무릎·총/팔은 유지하고, 머리는 목 피벗 기준 균등 확대했다. 수직 하단 조준 유지. 머리 8%는 시험값이며 사용자 수용 미확인이다.
- 발은 원본 body.png를 참고해 생성한 `original-front-foot-design-v1.png`의 발목 아래 영역만 사용했다. 생성 이미지의 나머지 신체 변경은 사용하지 않는다. 반투명 배경 잔상이 있어 시험 렌더러에서 alpha cutoff 0.9와 발 외곽 UV 다각형을 적용했다. 정식 자산 이식 전 알파/외곽과 발목 연결을 재검토해야 한다.
- 재현: 새 Play에서 원본 정면 ShowAngle(0), aim.enabled=false 후 일시정지 → `original-front-head-feet-trial.csx` → 발용 material을 `Unlit/Transparent Cutout`/cutoff 0.9로 바꾼 뒤 `original-front-feet-outline.csx`. 임시 시험이며 Unity 씬/원본 atlas/코드는 저장 변경하지 않았다. Play 종료로 복구했다.

## 최신: Unity 연속 비교용 씬 저장

사용자 요청으로 `SideScrollFrontStandingReview.unity`를 별도로 저장했다. 최신 실행/검토 방법은 `FRONT-STANDING-REVIEW.ko.md`를 본다. 새 atlas/material에 의상 세 부위와 발을 통합하고, 원본 정면 상체·다리 비율 및 팔/총 원본을 보존했다. 머리 확대는 새 씬에서만 1.08, 기존 씬의 기본값은 1이다. 원본 atlas와 기존 시험/측면/네트워크 씬은 그대로다.

이 단계에서는 사용자에게 직접 연속 비교를 보여주기 위해 새 씬 Play의 자동 비교를 켠 상태로 남겼다. 자동 전환 6자세와 기존 몸 안 조준/자세 복귀를 확인했고 콘솔 오류는 없었다. 자연스러운 크기/전환이라는 사용자 승인은 아직 없다.

## 최신: 자동 비교 대신 직접 조작

사용자가 자동 비교 대신 기존 임시 사격 캐릭터의 실제 이동/사격 중 자세 전환을 확인하길 요청했다. `SideScrollRunRecoveryTrial.unity`의 캐릭터/씬을 복사한 `SideScrollFrontPlayableTrial.unity`가 현재 작업 씬이다. 상세 조작은 `FRONT-PLAYABLE-TRIAL.ko.md`. 새 정면 리그를 실제 조준/발사 시스템에 연결했고 자동 비교 컴포넌트는 넣지 않았다. 기존 원본 씬들은 보존했다.

실제 이동→정지 하단→발사→점프→측면 복귀→반대 방향을 검사했고 오류/그림 겹침은 발견하지 않았다. 자동 검사는 임시 입력을 원래 키보드/마우스로 복구한 뒤 종료했다. 이 씬을 Play 상태로 남겨 직접 조작할 수 있게 했다. 전환의 미적 완성/부위 크기 및 총구 정렬은 사용자 확인과 추가 조정 대상이다.

## 직접 조작 후 비율 피드백

사용자가 정면 전환 시 상체가 짧고 다리/허벅지가 길며 키가 커 보인다고 지적했다. 같은 루트/카메라/하단 -55도에서 `ProportionsCheck/side55.png`, `front55-head108.png`, `front55-head100.png`로 비교했다. 의상 생성 시 벨트 중심이 원본 source y≈680에서 y≈615로 올라가 복부가 짧아지고 허벅지가 길게 읽히는 문제가 확인됐다. 머리 확대 1.08도 머리 꼭대기 상승을 추가한다. 전체 다리/몸통 비선형 보정 대신 벨트·복부의 원본 높이 복구 및 머리 기본 크기로 비교하는 방향이다.

수정 결과: 추가 생성안은 전체 몸 위치가 바뀌어 기각했다. 기존 atlas에서 복부 중앙을 원본으로 복구하고 벨트/좁은 흰 장식 픽셀만 아래로 64px 이동한 v2 atlas를 만들었다. 해당 중앙 영역 밖 변경 0. Playable 씬에 새 material을 지정하고 headScale=1로 저장했다. 원본 측면 및 기존 자동 비교 씬은 그대로다. 동일 640×800 캡처에서 밝은 머리 최상단 y: 측면 201, 수정 전 정면108 188, 기본 머리/허리 복구 정면 198. 즉 머리 꼭대기 차이 13px→3px. 허리 장식은 약 22px 내려갔고 실제 다리/무릎/발 위치는 변하지 않았다. `ProportionsCheck/side-before-after.png`에 측면/수정 전/수정 후를 저장했다. 마우스/키보드/발사 입력을 복구하고 Play 상태로 남겼다. 최종 시각 승인은 아직 없다.
