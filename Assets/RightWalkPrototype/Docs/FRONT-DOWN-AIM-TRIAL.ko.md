# 정지 하단 사격 연결 시험

- 브라우저 `LocalTools/Analysis/FrontShootingSandbox`에서 확정한 파츠를 아틀라스와 좌표 데이터로 내보내 유니티에 연결한다. 이미지를 다시 생성하거나 원본 걷기 파츠를 덮어쓰지 않는다.
- 메뉴: `Tools > Right Walk Prototype > Build Front Down Aim Trial`.
- 생성 씬: `Assets/RightWalkPrototype/SideScrollFrontDownAimTrial.unity`. 원본 `SideScrollTestMap.unity`와 네트워크 씬은 유지한다.
- `FrontDownAimOverlay`가 붙은 시험 캐릭터에서만 동작한다. 정지 상태의 하단 각도 -90도부터 -55도까지 새 파츠를 사용하며, 그 밖에는 기존 자세로 복귀한다.
- 이동 중에는 우선 기존 자세를 사용한다. 이는 정지 연결을 먼저 검증하기 위한 시험 범위이며, 이동 하단 사격을 최종적으로 금지한 규칙이 아니다. 걷기와 결합한 시각 검증은 다음 단계다.
- 총구 위치와 방향은 기존 `RightFacingAimRig`의 공통 속성으로 전달하므로 조준선, 일반 사격, 명중 검사가 같은 출발점과 방향을 사용한다.
- 브라우저에서 확정한 팔 길이 보정·접합 단면·그립 위치를 그대로 사용한다. 측면 리그의 본 길이로 교체하지 않는다.
- 모든 파츠는 꼭짓점 4개의 affine quad다. 몸통과 머리의 비선형 격자 변형, 가로 확대, 관절 높이 이동, 다리 폭·벌림 보정은 제거했다. 비트맵을 다시 만들지 않으며 고정 몸통 메시는 자세 진입 때만 갱신한다.
- 머리는 원본 파츠를 목 중심으로 최대 7도 회전한다. 좌우 반전은 캐릭터 루트에서 처리한다.
- 기존 캐릭터의 전신 높이와 발바닥 위치만 기준으로 전체를 균등 배율로 표시한다. 정면 원화의 신체 비율과 파츠 상대 위치는 보존한다.
- 몸 안쪽 커서: 플레이어 콜라이더 안이면서 목보다 아래인 경우, 총구 뒤에 커서가 있어도 정면 하단 자세를 유지한다. 허용 각도 밖의 근거리 요청은 -90~-55도에 제한한다. 총알이 몸 안의 커서를 향해 역방향으로 꺾이지는 않는다.
- 이번 복구에서는 머리·총의 측면 대비 개별 크기를 추가 보정하지 않는다. 따라서 측면/정면의 총 크기 차이와 전환 위치 차이는 남으며, 보고서의 길이 비율은 1:1 통과 판정이 아닌 참고 측정값이다.
- 원본 측면 프리팹의 45도 제한은 유지한다. 이 시험 씬에서만 `maxAngle=90`으로 지정해 지상 -55도 전환이 실제로 가능하게 한다.
- 검증 산출물: `LocalTools/Analysis/FrontDownUnity/validation.json`, 정면 하단 -90/-55도, 측면 캡처, `comparison.png`(왼쪽 측면, 오른쪽 복구 정면), `body-cursor.png`(몸 안쪽 조준).
- 브라우저 원본 좌표 비교, 몸통·머리의 균등 배율과 4꼭짓점 확인, 몸 안/총구 뒤 커서, 몸 밖의 일반 측면·상단 조준 복귀, 좌우 명중 및 자세 복귀를 검사한다.
- 기존에 시험 씬을 열어 둔 경우 Play를 종료하고 씬을 다시 열어 복구된 설정을 불러온다. 기존 Play 인스턴스에는 새 씬 설정이 소급 적용되지 않는다.
- 정면/측면은 서로 다른 원화이므로 시점 변경 자체의 순간적인 실루엣 차이는 남는다. 중간 시점 원화나 3D 회전 효과를 추가한 작업은 아니다.
